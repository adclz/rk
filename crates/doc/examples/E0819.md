---
title: Variadic index not an integer
---
`...values[i]` reads an argument by its position, so `i` has an integer type, and a subrange counts as its base type. A BOOL, a REAL or a bit string cannot be a position.

```iecst
FUNCTION first : INT
    VAR_INPUT
        i : REAL;
        values : INT...;
    END_VAR
    first := ...values[i];
END_FUNCTION
```
