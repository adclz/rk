---
title: Location type mismatch
---
A located variable holds one value as wide as its address, so it is declared as an elementary type of that width.

The size character says how wide the channel a host binds is: `X` one bit, `B` eight, `W` sixteen, `D` thirty-two, `L` sixty-four. Any elementary type of that width will do, so `%IW` takes a WORD, an INT or a UINT, and `%ID` a DWORD, a DINT or a REAL. An enum, a subrange, an ARRAY, a STRUCT or a STRING has no single width, and is refused: declare the elementary type and convert in the program.

```iecst
PROGRAM P
VAR_EXTERNAL wide : INT; END_VAR
VAR t : INT; END_VAR
    t := wide;
END_PROGRAM

CONFIGURATION Cfg
VAR_GLOBAL wide AT %IX0.0 : INT; END_VAR
    RESOURCE R ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
