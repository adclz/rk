---
title: Location type mismatch
---
A located variable is an elementary type as wide as its address: `%IW` takes a WORD, an INT or a UINT, and `%ID` a DWORD, a DINT or a REAL.

An enum, a subrange, an ARRAY, a STRUCT or a STRING is refused.

```iecst
PROGRAM P
VAR_EXTERNAL wide : INT; END_VAR
VAR t : INT; END_VAR
    t := wide;
END_PROGRAM

CONFIGURATION Cfg
VAR_GLOBAL wide AT %IX0.0 : INT; END_VAR
    RESOURCE R ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
