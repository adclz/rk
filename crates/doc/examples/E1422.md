---
title: Location width mismatch
---
The size character of an address and the declared type disagree about how wide the value is.

The size character says how wide the channel a host binds is: `X` one bit, `B` eight, `W` sixteen, `D` thirty-two, `L` sixty-four. The declared type has to be that wide, so `%IW` takes a WORD, an INT or a UINT, and `%IX` takes a BOOL.

```iecst
PROGRAM P
VAR_EXTERNAL wide : INT; END_VAR
VAR t : INT; END_VAR
    t := wide;
END_PROGRAM

CONFIGURATION Cfg
VAR_GLOBAL wide AT %IX0.0 : INT; END_VAR
    RESOURCE R ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
