---
title: Type mismatch
---
The types on both sides of an assignment or expression are incompatible.

A `STRUCT` written in place is a type of its own, so two written alike are incompatible too. Declare it in a `TYPE` to use it in both places.

```iecst
FUNCTION_BLOCK fb1
VAR
    x : INT;
    s : STRING;
END_VAR
    x := s;
END_FUNCTION_BLOCK
```
