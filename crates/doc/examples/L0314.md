---
title: Positional output
lint_rule: positional-output
---
A positional argument stands in the place of a VAR_OUTPUT, and receives the output. A positional list gives every parameter in declaration order, outputs included.

Legal, but nothing at the call site says the variable is written. `o => y` says so.

```iecst
FUNCTION first : INT
VAR_OUTPUT o : INT; END_VAR
VAR_INPUT a : INT; END_VAR
    o := a * 10;
    first := 0;
END_FUNCTION

FUNCTION caller : INT
VAR y : INT; END_VAR
    caller := first(y, 4);
END_FUNCTION
```
