---
title: VAR_ACCESS type mismatch
---
A `VAR_ACCESS` declaration's type does not match the referenced variable's actual type.

```iecst
PROGRAM prog1
VAR
    my_var : INT;
END_VAR
VAR_ACCESS
    accessor : my_var : BOOL;
END_VAR
END_PROGRAM

CONFIGURATION config1
    RESOURCE res1 ON CPU
        TASK task1(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM inst1 WITH task1 : prog1;
    END_RESOURCE
END_CONFIGURATION
```
