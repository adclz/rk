---
title: VAR_ACCESS not supported
---
A `VAR_ACCESS` section, in a PROGRAM or a CONFIGURATION, names variables for another device to read or write by name. No host of rk serves such a name: a host reads and writes a variable by its path. Remove the section.

```iecst
PROGRAM Main
VAR count : INT; END_VAR
    count := count + 1;
END_PROGRAM

CONFIGURATION Plant
    RESOURCE Res ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : Main;
    END_RESOURCE
    VAR_ACCESS
        total : Res.P1.count : INT READ_ONLY;
    END_VAR
END_CONFIGURATION
```
