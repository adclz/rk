---
title: Literal out of range
---
The literal is well-formed but outside what the type can hold.
The message ends with the type's bounds.
A radix literal (`2#`, `8#`, `16#`) is a bit pattern of the type's width instead: `SINT#16#FF` is -1, and `SINT#16#1FF` has one bit too many.

```iecst
FUNCTION_BLOCK fb1
VAR
    test: INT := 32768;
END_VAR
END_FUNCTION_BLOCK
```
