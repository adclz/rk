---
title: Missing required parameter
---
A FUNCTION or METHOD call has to supply every VAR_INPUT that has no default.

A default is a constant of an elementary type, STRING included. A STRUCT or ARRAY initializer on an input is not a default, and is refused where it is written (E0407).

Name the missing parameter in the call.

```iecst
FUNCTION add2 : INT
VAR_INPUT a : INT; b : INT; END_VAR
    add2 := a + b;
END_FUNCTION

FUNCTION f1 : INT
    f1 := add2(a := 1);
END_FUNCTION
```
