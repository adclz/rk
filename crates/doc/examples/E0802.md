---
title: Missing required parameter
---
A FUNCTION call must supply every VAR_INPUT (inputs have no defaults on FUNCTIONs). Name the missing parameter in the call.

```iecst
FUNCTION add2 : INT
VAR_INPUT a : INT; b : INT; END_VAR
    add2 := a + b;
END_FUNCTION

FUNCTION f1 : INT
    f1 := add2(a := 1);
END_FUNCTION
```
