---
title: VAR_IN_OUT argument not a variable
---
A VAR_IN_OUT of a `FUNCTION` or a `METHOD` is bound by reference, and a `FUNCTION_BLOCK`'s scalar one is copied in and back: either way the argument is a variable, not an expression or a literal.

A slice of a variable, `b.%X1`, has no address of its own to bind; a `FUNCTION_BLOCK` copies one in and back like any value.

```iecst
FUNCTION bump : INT
VAR_IN_OUT io : INT; END_VAR
    io := io + 1;
    bump := io;
END_FUNCTION

FUNCTION f1 : INT
    f1 := bump(io := 1 + 2);
END_FUNCTION
```
