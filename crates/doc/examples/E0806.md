---
title: VAR_IN_OUT argument not a variable
---
A VAR_IN_OUT is passed by reference. The argument is a variable, not an expression or a literal.

```iecst
FUNCTION bump : INT
VAR_IN_OUT io : INT; END_VAR
    io := io + 1;
    bump := io;
END_FUNCTION

FUNCTION f1 : INT
    f1 := bump(io := 1 + 2);
END_FUNCTION
```
