---
title: VAR_IN_OUT argument must be a variable
---
A VAR_IN_OUT parameter is passed by reference: the argument must be an assignable variable, not an expression or a literal.

```iecst
FUNCTION bump : INT
VAR_IN_OUT io : INT; END_VAR
    io := io + 1;
    bump := io;
END_FUNCTION

FUNCTION f1 : INT
    f1 := bump(io := 1 + 2);
END_FUNCTION
```
