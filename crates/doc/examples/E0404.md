---
title: Constant changed
---
A constant keeps the value it is declared with. Nothing writes it: not an assignment, an output, a `FOR` counter or a bit, to it or to a field or an element of it. Nor can it be passed to a `VAR_IN_OUT` or to `REF()`, which could change it.

A FUNCTION_BLOCK or CLASS instance cannot be CONSTANT: it changes when it runs.

```iecst
FUNCTION_BLOCK fb1
VAR CONSTANT
    x : INT := 10;
END_VAR
    x := 20;
END_FUNCTION_BLOCK
```
