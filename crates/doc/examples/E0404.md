---
title: Write to a constant
---
A constant keeps the value it is declared with.

No assignment, output binding, `FOR` counter or bit access writes it, nor a field or an element of it. It cannot be passed to a `VAR_IN_OUT` or to `REF()` either: both could change it.

A FUNCTION_BLOCK or CLASS instance cannot be CONSTANT: it changes when it runs.

```iecst
FUNCTION_BLOCK fb1
VAR CONSTANT
    x : INT := 10;
END_VAR
    x := 20;
END_FUNCTION_BLOCK
```
