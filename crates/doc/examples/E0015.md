---
title: THIS used as a path member
---
`THIS` may only start a path expression (`THIS.member`, `THIS^.member`). It is not a member name, so it cannot appear after a dot. Using `THIS` in a POU that has no instance — a FUNCTION — is reported as E1105 instead.

```iecst
FUNCTION_BLOCK fb1
VAR
    x : INT;
END_VAR
    x := x.THIS;
END_FUNCTION_BLOCK
```
