---
title: VAR_IN_OUT not allowed in this context
---
`VAR_IN_OUT` declares a parameter of a FUNCTION, FUNCTION_BLOCK, PROGRAM or METHOD, or of a METHOD prototype in an INTERFACE. A CLASS has no body and a CONFIGURATION no call to pass one to.

```iecst
CLASS c1
    VAR_IN_OUT

    END_VAR
END_CLASS
```
