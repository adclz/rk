---
title: Unreachable code
lint_rule: dead-code
---
A statement follows a RETURN, EXIT, CONTINUE or `__RAISE` in the same block. It never runs.

It is checked like any other statement: an unknown name or a type mismatch there is reported.

```iecst
FUNCTION test : INT
    test := 1;
    RETURN;
    test := 2;
END_FUNCTION
```
