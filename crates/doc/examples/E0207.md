---
title: External variable type mismatch
---
A VAR_EXTERNAL repeats its VAR_GLOBAL's type exactly, subrange included, or it would bypass the global's range check.

```iecst
TYPE Small : INT (0..10); END_TYPE

PROGRAM MyProg
    VAR_EXTERNAL
        g : INT;
    END_VAR
END_PROGRAM

CONFIGURATION MyCfg
    VAR_GLOBAL
        g : Small;
    END_VAR
    RESOURCE Res ON CPU
        TASK t1(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM inst1 WITH t1 : MyProg;
    END_RESOURCE
END_CONFIGURATION
```
