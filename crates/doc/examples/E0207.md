---
title: VAR_EXTERNAL type mismatch
---
A VAR_EXTERNAL repeats the type of its VAR_GLOBAL exactly, subrange included. A wider type would bypass the global's range check.

```iecst
TYPE Small : INT (0..10); END_TYPE

PROGRAM MyProg
    VAR_EXTERNAL
        g : INT;
    END_VAR
END_PROGRAM

CONFIGURATION MyCfg
    VAR_GLOBAL
        g : Small;
    END_VAR
    RESOURCE Res ON CPU
        TASK t1(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM inst1 WITH t1 : MyProg;
    END_RESOURCE
END_CONFIGURATION
```
