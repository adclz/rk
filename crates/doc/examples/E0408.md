---
title: Constant defined by its own value
---
A constant's value is computed before the program runs, from the constants it names. A value that reads the constant itself, directly or through other constants, has nothing to start from.

```iecst
FUNCTION Limits : INT
VAR CONSTANT
    HIGH : INT := LOW + 10;
    LOW : INT := HIGH - 10;
END_VAR
    Limits := 0;
END_FUNCTION
```
