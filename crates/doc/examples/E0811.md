---
title: Type that cannot be variadic
---
A variadic parameter (`...`) takes an elementary type, or an alias of one. A STRING, a subrange, a STRUCT and any other composite type cannot be variadic.

```iecst
TYPE MyStruct :
    STRUCT
        field1: INT;
    END_STRUCT
END_TYPE

FUNCTION sum_all : INT
    VAR_INPUT
        args: MyStruct...
    END_VAR
END_FUNCTION
```
