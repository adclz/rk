---
title: Non-variadic type for variable
---
Only elementary types can be declared as variadic (`...`). Structs and other composite types cannot.

```iecst
TYPE MyStruct :
    STRUCT
        field1: INT;
    END_STRUCT
END_TYPE

FUNCTION sum_all : INT
    VAR_INPUT
        args: MyStruct...
    END_VAR
END_FUNCTION
```
