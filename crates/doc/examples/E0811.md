---
title: Variadic parameter of a composite type
---
Only an elementary type can be variadic (`...`). A STRUCT or another composite type cannot.

```iecst
TYPE MyStruct :
    STRUCT
        field1: INT;
    END_STRUCT
END_TYPE

FUNCTION sum_all : INT
    VAR_INPUT
        args: MyStruct...
    END_VAR
END_FUNCTION
```
