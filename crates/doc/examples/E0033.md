---
title: Compound assignment outside a statement
---
A compound assignment, `count += 1;`, is a statement of its own, or a place of a chain, `total := count += 1;`. In a call's argument, at the start of a `FOR` or in a condition, it is refused: write it in a statement before. In a condition, `IF count += 1 THEN` would otherwise be one deleted `+` away from `IF count = 1 THEN`, which compiles and compares.

```iecst
FUNCTION Twice : INT
VAR_INPUT v : INT; END_VAR
    Twice := v * 2;
END_FUNCTION

FUNCTION Use : INT
VAR i, count : INT; END_VAR
    Use := Twice(v := count += 1);
    FOR i := count += 1 TO 10 DO
        Use := Use + i;
    END_FOR;
    IF count += 1 THEN
        Use := 0;
    END_IF;
END_FUNCTION
```
