---
title: Compound assignment outside a statement
---
A compound assignment, `count += 1;`, is a statement of its own. After a place of a chain, in a call's argument or after another compound assignment's value, it is refused: write it in a statement before.

```iecst
FUNCTION Twice : INT
VAR_INPUT v : INT; END_VAR
    Twice := v * 2;
END_FUNCTION

FUNCTION Use : INT
VAR total, count : INT; END_VAR
    total := count += 1;
    Use := Twice(v := count += 1);
END_FUNCTION
```
