---
title: Located variable overwritten
---
A variable declared `AT %I*`, `%Q*` or `%M*` points at the channel `VAR_CONFIG` gives its instance. What would write over that pointer is refused:

- an initializer that names the variable, such as `d : Drive := (out := 30)`. The variable starts at its type's default, or at the value the channel's own declaration gives it;
- assigning an instance of a CLASS that holds the variable. The copy would point at the channels of the instance it copies. Assign the variables that hold values one by one.

```iecst
FUNCTION_BLOCK Drive
VAR out AT %Q* : INT; END_VAR
END_FUNCTION_BLOCK

PROGRAM P
VAR d : Drive := (out := 30); END_VAR
END_PROGRAM

CONFIGURATION Cfg
VAR_CONFIG
    Res.P1.d.out AT %QW0 : INT;
END_VAR
    RESOURCE Res ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
