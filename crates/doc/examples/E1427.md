---
title: Located variable overwritten
---
A variable declared `AT %I*`, `%Q*` or `%M*` points at the address `VAR_CONFIG` gives it, so an instance initializer cannot set it.

Give its starting value in the `VAR_CONFIG` entry.

```iecst
FUNCTION_BLOCK Drive
VAR out AT %Q* : INT; END_VAR
END_FUNCTION_BLOCK

PROGRAM P
VAR d : Drive := (out := 30); END_VAR
END_PROGRAM

CONFIGURATION Cfg
VAR_CONFIG
    Res.P1.d.out AT %QW0 : INT;
END_VAR
    RESOURCE Res ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
