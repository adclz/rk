---
title: Constant operation out of range
lint_rule: constant-overflow
---
An operation on constants gives a result the type it runs at cannot hold, so the program computes it wrapped: `32767 + 1` on INT is -32768.

An operation runs at the type of its operands, and two untyped literals make an INT, whatever receives the result: `N : DINT := 200 * 200` holds -25536, and `STRING[300 * 300]` holds 24464 bytes.
Give one operand the wider type, `DINT#200 * 200`.

```iecst
FUNCTION Demo : DINT
VAR CONSTANT
    N : DINT := 200 * 200;
END_VAR
    Demo := N;
END_FUNCTION
```
