---
title: Incomplete subscript
---
A multi-dimensional array is indexed in all its dimensions: `m[1]` of an `ARRAY[0..1, 0..2]` names a part of it, which no assignment, call or comparison can take.
Subscript every dimension, `m[1, 2]` or `m[1][2]`, or declare an array of an array type when a row is what the program needs.

```iecst
FUNCTION f1 : INT
VAR
    m : ARRAY[0..1, 0..2] OF INT;
    n : ARRAY[0..1, 0..2] OF INT;
END_VAR
    n := m[1];
END_FUNCTION
```
