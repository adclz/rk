---
title: Incomplete subscript
---
A multi-dimensional array is indexed in all its dimensions. `m[1]` of an `ARRAY[0..1, 0..2]` is only a part of the array, and no assignment, call or comparison takes a part.

Subscript every dimension, `m[1, 2]` or `m[1][2]`, or declare an array of an array type when a row is what the program needs.

```iecst
FUNCTION f1 : INT
VAR
    m : ARRAY[0..1, 0..2] OF INT;
    n : ARRAY[0..1, 0..2] OF INT;
END_VAR
    n := m[1];
END_FUNCTION
```
