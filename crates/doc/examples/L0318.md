---
title: Code left in a comment
lint_rule: commented-out-code
---
A comment holds statements: code that was commented out and left there.

Code in a comment is easily put back by mistake.
Nothing checks it while it sits there.
Delete it: version control keeps the old lines.

A comment counts as code when its text parses as the statements of a body.
Line comments on consecutive lines are read as one comment.

```iecst
PROGRAM Line
VAR
    count : INT;
END_VAR
    count := count + 1;
    // count := 0;
    // Reset();
END_PROGRAM
```
