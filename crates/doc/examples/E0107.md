---
title: Variable is the return value
---
Inside a FUNCTION or a value-returning METHOD, the callable's own name is its return value, so a variable declared with that name (in any case: identifiers are not case sensitive) is a second declaration of it. The body would bind to the local, at the local's type, while the signature still promises the return type's.

```iecst
FUNCTION fn1 : INT
VAR
    fn1 : LINT;
END_VAR
    fn1 := 1;
END_FUNCTION
```
