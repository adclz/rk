---
title: Once-function called multiple times
lint_rule: once-violation
---
A function, function block, or method marked with `{once}` is called more than once in the same body.
The `{once}` pragma indicates it should only be invoked once per execution cycle.

```iecst
{once}
FUNCTION init : INT
    init := 42;
END_FUNCTION

FUNCTION caller : INT
VAR x : INT; y : INT; END_VAR
    x := init();
    y := init();
    caller := x + y;
END_FUNCTION
```
