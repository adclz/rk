---
title: {once} POU called more than once
lint_rule: once-violation
---
A POU marked `{once}` is called more than once in the same body. `{once}` means one call per execution cycle.

```iecst
{once}
FUNCTION init : INT
    init := 42;
END_FUNCTION

FUNCTION caller : INT
VAR x : INT; y : INT; END_VAR
    x := init();
    y := init();
    caller := x + y;
END_FUNCTION
```
