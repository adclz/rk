---
title: Read before it has its value
---
An initial value of a FUNCTION or METHOD reads one of its variables that gets its value after it, or itself.

The variables take their values at each call, in the order they are declared, so the read sees 0: declare the variable it reads first. An input, a CONSTANT and a `REF()` can be named in any order.

```iecst
FUNCTION F : INT
VAR_INPUT n : INT; END_VAR
VAR
    a : INT := b;
    b : INT := n + 1;
END_VAR
    F := a;
END_FUNCTION
```
