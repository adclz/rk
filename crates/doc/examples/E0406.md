---
title: Read before initialization
---
An initial value of a FUNCTION or METHOD reads a variable declared after it, or itself.

The variables take their values at each call, in declaration order, so the read sees 0. Declare the variable it reads first.

An input, a CONSTANT and a `REF()` can be named in any order.

```iecst
FUNCTION F : INT
VAR_INPUT n : INT; END_VAR
VAR
    a : INT := b;
    b : INT := n + 1;
END_VAR
    F := a;
END_FUNCTION
```
