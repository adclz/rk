---
title: Address in a library
---
A library is code for any machine: it names no complete address, in an `AT` or in a body. The workspace maps the hardware.

Declare the variable `AT %I*`, `%Q*` or `%M*` in the library's block, and locate each instance in the `VAR_CONFIG` of the workspace's configuration. A signal the library reads from the machine is a `VAR_EXTERNAL` of the block, declared `VAR_GLOBAL` with its address in the workspace.

This holds for every dependency, a `path` as a `url`, and for the standard library. The error is reported when a workspace builds with the library.
