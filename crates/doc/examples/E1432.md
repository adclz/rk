---
title: Address in a library
---
A library is code for any machine: it names no complete address, in an `AT` or in a body. The workspace maps the hardware.

Declare the variable `AT %I*`, `%Q*` or `%M*` in the library's block, and locate each instance in the `VAR_CONFIG` of the workspace's configuration, or take the signal as an input of the block. A library sees no global (`E1008`).

This holds for every dependency, a `path` as a `url`, and for the standard library. The error is reported when a workspace builds with the library, and in the library's own folder, whose `config.toml` says `type = "library"`.
