---
title: clause of a __TRY written twice
---
A `__TRY` can only have one `__CATCH` and one `__FINALLY`.

There is only one kind of exception in rk.
A single `__CATCH` already catches all of them.

```iecst
FUNCTION f1 : INT
    __TRY
        f1 := 1;
    __CATCH
        f1 := 2;
    __CATCH
        f1 := 3;
    __END_TRY;
END_FUNCTION
```
