---
title: Duplicate RESOURCE name
---
Two RESOURCE blocks in the same configuration have the same name.

```iecst
CONFIGURATION config1
    RESOURCE res1 ON CPU
        TASK task1(PRIORITY := 1);
    END_RESOURCE
    RESOURCE res1 ON CPU
        TASK task2(PRIORITY := 1);
    END_RESOURCE
END_CONFIGURATION
```
