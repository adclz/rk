---
title: Configuration in a library
---
A library is code for any machine: it declares no CONFIGURATION. The configuration, its globals, its resources and its tasks are the program's that lists the library.

Move the CONFIGURATION to a program that lists the library. A block of the library takes what it needs through its inputs and in-outs, and a variable it declares `AT %I*`, `%Q*` or `%M*` is located by the program's `VAR_CONFIG`.

The error is reported when a program builds with the library, and in the library's own folder, whose `config.toml` says `type = "library"`.
