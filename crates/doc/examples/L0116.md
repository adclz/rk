---
title: Method variable shadows an owner member
lint_rule: method-shadows-member
---
A method's local or parameter has the same name as a member of the function block or class it belongs to. This is legal — the method variable shadows the member and bare-name access resolves to the local — but it is easy to misread.

```iecst
FUNCTION_BLOCK Counter
VAR
    c : INT;
END_VAR
    METHOD Inc : INT
    VAR
        c : INT;
    END_VAR
        c := c + 1;
        Inc := c;
    END_METHOD
END_FUNCTION_BLOCK
```
