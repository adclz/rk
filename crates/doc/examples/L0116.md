---
title: Method variable shadows an owner member
lint_rule: method-shadows-member
---
A method's local or parameter has the name of a member of its block.

It is legal, and the local wins, but easy to misread.

```iecst
FUNCTION_BLOCK Counter
VAR
    c : INT;
END_VAR
    METHOD Inc : INT
    VAR
        c : INT;
    END_VAR
        c := c + 1;
        Inc := c;
    END_METHOD
END_FUNCTION_BLOCK
```
