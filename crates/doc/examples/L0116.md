---
title: Method variable named after a member
lint_rule: method-shadows-member
---
A method's local or parameter has the name of a member of its block. This is legal, and the local wins, but the two are easy to confuse.

```iecst
FUNCTION_BLOCK Counter
VAR
    c : INT;
END_VAR
    METHOD Inc : INT
    VAR
        c : INT;
    END_VAR
        c := c + 1;
        Inc := c;
    END_METHOD
END_FUNCTION_BLOCK
```
