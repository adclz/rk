---
title: Negated condition
lint_rule: negated-condition
---
An `IF NOT ... THEN ... ELSE` can be simplified by swapping the branches and removing the negation.

```iecst
FUNCTION test : INT
VAR
    flag : BOOL;
END_VAR
    IF NOT flag THEN
        test := 0;
    ELSE
        test := 1;
    END_IF;
END_FUNCTION
```
