---
title: Assignment sign ':=' in a condition
---
A condition compares, so it takes `=`.
`:=` assigns, and writing one where the language expects a test is almost always a typo for the other.

```iecst
FUNCTION_BLOCK fb1
VAR
    x: INT;
END_VAR
    IF x := 1 THEN
        x := 2;
    END_IF;
END_FUNCTION_BLOCK
```
