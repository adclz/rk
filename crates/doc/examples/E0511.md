---
title: Element of an ARRAY[*] of any type
---
An `ARRAY[*]` with no `OF` is an array of any type. Its elements have no type to read or write: it is passed on, or has its bounds read.

Give it an element type to index it, as in `ARRAY[*] OF INT`.

```iecst
FUNCTION First : INT
VAR_IN_OUT
    values : ARRAY[*];
END_VAR
    First := values[1];
END_FUNCTION
```
