---
title: Instantiation of an ABSTRACT type
---
An ABSTRACT CLASS or FUNCTION_BLOCK has no implementation of its own, so it cannot be instantiated. Declare a variable of a derived type instead.

```iecst
CLASS ABSTRACT Base
    METHOD PUBLIC ABSTRACT myMethod : INT  END_METHOD
END_CLASS

PROGRAM Main
VAR
    b : Base;
END_VAR
END_PROGRAM
```
