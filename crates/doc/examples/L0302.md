---
title: Unused return value
lint_rule: unused-return-type
---
A function call discards a return value.
If the return value is intentionally ignored, assign it to a variable.

```iecst
FUNCTION add : INT
VAR_INPUT
    a : INT;
    b : INT;
END_VAR
    add := a + b;
END_FUNCTION

FUNCTION_BLOCK fb1
    add(a := 1, b := 2);
END_FUNCTION_BLOCK
```
