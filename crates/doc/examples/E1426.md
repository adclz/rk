---
title: Configuration entry refused
---
A `VAR_CONFIG` entry names a variable by a path that starts at a PROGRAM instance and goes through the instances it holds, such as `Res.P1.d.level`, and repeats the variable's type.

The entry is refused when:

- the type it writes is not the one the variable is declared with;
- its path indexes an array or dereferences a reference. A path names instances and variables by name only.

```iecst
PROGRAM P
VAR level AT %I* : INT; END_VAR
END_PROGRAM

CONFIGURATION Cfg
VAR_CONFIG
    Res.P1.level AT %IW2 : UINT;
END_VAR
    RESOURCE Res ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
