---
title: Configuration entry refused
---
A `VAR_CONFIG` entry names a variable by its path from a PROGRAM instance and repeats its type: `Res.P1.d.level : INT := 5;`.

The path names instances and variables only, and each variable gets one entry.

```iecst
PROGRAM P
VAR level AT %I* : INT; END_VAR
END_PROGRAM

CONFIGURATION Cfg
VAR_CONFIG
    Res.P1.level AT %IW2 : UINT;
END_VAR
    RESOURCE Res ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
