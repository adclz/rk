---
title: Type contains itself
---
A type contains a member of its own type by value: a STRUCT with a field of its own type, or a FUNCTION_BLOCK with an instance of itself. Such a type would have no finite size.

A member held by address, a REF_TO, is no part of the type and makes no cycle.

```iecst
TYPE s1 : STRUCT
    field1 : s1;
END_STRUCT
END_TYPE
```
