---
title: Unsupported configuration element
---
Program connections (`inp := %IW1`) and per-FB task associations inside a program configuration are not supported. A value a `VAR_CONFIG` entry gives (`Res.P1.x : INT := 5;`) is checked but not applied yet.

```iecst
PROGRAM P
VAR_INPUT inp : INT; END_VAR
VAR n : INT; END_VAR
    n := inp;
END_PROGRAM

CONFIGURATION Cfg
    RESOURCE Res ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : P (inp := %IW1);
    END_RESOURCE
END_CONFIGURATION
```
