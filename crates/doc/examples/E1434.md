---
title: RETAIN mismatch on shared bytes
---
When `config.toml` numbers addresses by byte, two addresses can share bytes with neither holding the other: `%MW7` is bytes 7 and 8, and `%MW8` bytes 8 and 9. They are stored together, and persist together or not at all: when the variable located at one of them is `RETAIN`, the variables located at the others must be `RETAIN` too.

An address inside one of them is part of it, and its persistence is that address's to declare (`E1423`).

```toml
[addresses]
numbering = "byte"
```

```iecst
PROGRAM P
VAR_EXTERNAL first : WORD; second : WORD; END_VAR
    first := second;
END_PROGRAM

CONFIGURATION C
    VAR_GLOBAL RETAIN
        first AT %MW7 : WORD;
    END_VAR
    VAR_GLOBAL
        second AT %MW8 : WORD;
    END_VAR
    RESOURCE R ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM Main WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
