---
title: ARRAY[*] argument not a variable
---
An `ARRAY[*]` parameter is bound to a variable, or a row of one, and takes its bounds. A literal, an expression or a call result is no variable.

Store the value in a variable, and pass the variable.

```iecst
TYPE Four : ARRAY[0..3] OF INT; END_TYPE

FUNCTION Readings : Four
END_FUNCTION

FUNCTION Count : DINT
VAR_INPUT
    values : ARRAY[*] OF INT;
END_VAR
    Count := 4;
END_FUNCTION

FUNCTION Demo : DINT
    Demo := Count(Readings());
END_FUNCTION
```
