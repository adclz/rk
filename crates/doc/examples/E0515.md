---
title: Repetition outside an array's brackets
---
A repetition, `2(1, 2)`, writes elements of an array, inside the brackets of the array's value: `[2(1, 2)]`.

A field's or a member's value is written whole. An array there takes its brackets too.

```iecst
TYPE Recipe : STRUCT
    steps : ARRAY[0..3] OF INT;
END_STRUCT; END_TYPE

PROGRAM P
VAR
    r : Recipe := (steps := 2(1, 2));
END_VAR
    r.steps[0] := r.steps[1];
END_PROGRAM
```
