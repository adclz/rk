---
title: Two qualifiers on a declaration
---
A struct element, a variable section or a program instance takes one qualifier: `CONSTANT`, `RETAIN` or `NON_RETAIN`. Keep the one you mean.

```iecst
TYPE
    Counter : STRUCT
        RETAIN NON_RETAIN count : DINT;
    END_STRUCT;
END_TYPE

PROGRAM Main
VAR RETAIN NON_RETAIN
    total : DINT;
END_VAR
    total := total + 1;
END_PROGRAM
```
