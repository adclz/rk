---
title: Subrange bound is not a constant
---
A subrange's bounds are part of the type, so each must evaluate to a constant at compile time. A named CONSTANT and folding arithmetic are fine; an ordinary variable is not.

```iecst
FUNCTION f1 : INT
VAR
    n : INT;
    x : INT (0..n);
END_VAR
END_FUNCTION
```
