---
title: Ambiguous overloaded call
---
A call matches more than one FUNCTION overload and no overload is an exact match for every argument, so the compiler refuses to guess. Disambiguate with a typed literal or an explicit conversion (e.g. `DINT#5`).

```iecst
FUNCTION pick : INT
VAR_INPUT x : DINT; END_VAR
    pick := 1;
END_FUNCTION

FUNCTION pick : INT
VAR_INPUT x : LINT; END_VAR
    pick := 2;
END_FUNCTION

FUNCTION caller : INT
VAR y : SINT; END_VAR
    // SINT widens to both DINT and LINT — neither overload is exact.
    caller := pick(y);
END_FUNCTION
```
