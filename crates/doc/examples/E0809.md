---
title: Ambiguous overloaded call
---
The call matches several overloads, and none exactly.

Make it exact with a typed literal or a conversion, such as `DINT#5`.

```iecst
FUNCTION pick : INT
VAR_INPUT x : DINT; END_VAR
    pick := 1;
END_FUNCTION

FUNCTION pick : INT
VAR_INPUT x : LINT; END_VAR
    pick := 2;
END_FUNCTION

FUNCTION caller : INT
VAR y : SINT; END_VAR
    // SINT widens to both DINT and LINT — neither overload is exact.
    caller := pick(y);
END_FUNCTION
```
