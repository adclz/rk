---
title: Info pragma notice
lint_rule: warn-pragma
---
A call targets a POU annotated with `{info = '...'}`, providing an informational notice at the call site.

```iecst
{info = 'prefer new_fn for better performance'}
FUNCTION old_fn : INT
END_FUNCTION

FUNCTION caller : INT
VAR x : INT; END_VAR
    x := old_fn();
END_FUNCTION
```
