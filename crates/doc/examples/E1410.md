---
title: Unschedulable TASK
---
A TASK runs on its INTERVAL and on each rising edge of its SINGLE. A task that runs a PROGRAM or a function block needs one of them: an INTERVAL above zero, written as a literal or a CONSTANT, or a SINGLE that can rise, which is a BOOL with a place in memory: a VAR_GLOBAL, a program's VAR_OUTPUT, or the address of a bit. A constant SINGLE never rises: FALSE alone would never run the task, and TRUE would run it once and stop its INTERVAL.

```iecst
PROGRAM P
VAR n : INT; END_VAR
    n := n + 1;
END_PROGRAM

CONFIGURATION Cfg
    RESOURCE Res ON CPU
        TASK T(SINGLE := TRUE, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
