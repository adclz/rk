---
title: Unschedulable TASK
---
A TASK is scheduled by a cyclic INTERVAL. SINGLE (event-driven) tasks are not supported by the scan dispatcher.

```iecst
PROGRAM P
VAR n : INT; END_VAR
    n := n + 1;
END_PROGRAM

CONFIGURATION Cfg
    RESOURCE Res ON CPU
        TASK T(SINGLE := TRUE, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
