---
title: Internal namespace accessed from outside
---
A NAMESPACE INTERNAL is reachable only from inside the namespace that holds it, in the same library.

At the top level, INTERNAL means this library only.

```iecst
NAMESPACE Lib
    NAMESPACE INTERNAL Impl
        FUNCTION hidden : INT
            hidden := 1;
        END_FUNCTION
    END_NAMESPACE
END_NAMESPACE

FUNCTION use : INT
    use := Lib.Impl.hidden();
END_FUNCTION
```
