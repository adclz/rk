---
title: Export name not a WIT name
---
A host calls an `{export}` FUNCTION by a WIT name: its namespaces' names and its own, each in lowercase with `_` written `-`, joined by `-`. `Motion.Scale_Axis` is `motion-scale-axis`.

A name that leaves a word empty, like `_Reset`, or that has a letter outside ASCII, gives no WIT name. Two exports cannot have one name, and the component model compares names without their `-`. `{export 'name'}` names the export itself, in words of lowercase letters and digits joined by `-`.

Each `VAR_INPUT` and `VAR_OUTPUT` is named the same way: `start_address` is `start-address`. The `VAR_OUTPUT` are the fields of the record the export returns, and the return value is its last, named as the export is: no `VAR_OUTPUT` can take that name.

```iecst
{export}
FUNCTION _Reset : INT
    _Reset := 0;
END_FUNCTION
```
