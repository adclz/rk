---
title: Async import in a call's frame
---
The host writes an async call's result into its block's instance when the call finishes, at a later scan. A FUNCTION's or a METHOD's variables, and a VAR_TEMP, are gone by then.

So an async import's instance, or an instance holding one, lives in a PROGRAM, a FUNCTION_BLOCK or a VAR_GLOBAL. A FUNCTION can still call one it does not hold: the caller's, handed over as VAR_IN_OUT, or a global's, through VAR_EXTERNAL.

```iecst
{extern async 'wasi:clocks/monotonic-clock@0.3.0' 'wait-for'}
FUNCTION_BLOCK WAIT_FOR
VAR_INPUT how_long : LTIME; END_VAR
VAR_OUTPUT DONE : BOOL; END_VAR
END_FUNCTION_BLOCK

FUNCTION Pause
VAR wait : WAIT_FOR; END_VAR
    wait(how_long := LT#1s);
END_FUNCTION
```
