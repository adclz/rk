---
title: Unknown TASK reference
---
The task named by a `WITH`, after a program instance or after a function block of its list, is not a TASK of this configuration.

```iecst
PROGRAM prog1
END_PROGRAM

CONFIGURATION config1
    RESOURCE res1 ON CPU
        PROGRAM inst1 WITH unknown_task : prog1;
    END_RESOURCE
END_CONFIGURATION
```
