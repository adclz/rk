---
title: Wasm pragma outside a FUNCTION
---
A `{wasm}` intrinsic is only read in a FUNCTION body. Anywhere else the pragma would have no effect.

```iecst
FUNCTION_BLOCK FB
VAR_INPUT
    a : INT;
END_VAR
VAR_OUTPUT
    o : INT;
END_VAR
    {wasm 'i32.shl' (params a a) (result o)}
END_FUNCTION_BLOCK
```
