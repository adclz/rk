---
title: Wasm pragma outside a FUNCTION
---
Only FUNCTION bodies are scanned for a {wasm} intrinsic; anywhere else the pragma was silently dropped and the surrounding body compiled as if it were not there.

```iecst
FUNCTION_BLOCK FB
VAR_INPUT
    a : INT;
END_VAR
VAR_OUTPUT
    o : INT;
END_VAR
    {wasm 'i32.shl' (params a a) (result o)}
END_FUNCTION_BLOCK
```
