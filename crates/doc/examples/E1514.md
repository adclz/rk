---
title: Async import without its DONE
---
An `{extern async}` FUNCTION_BLOCK is an async import. Each call of the block takes its call one step: it starts the call when none is running, and checks it otherwise, never waiting.

Its VAR_OUTPUT `DONE : BOOL` is TRUE in the call of the block that saw the call finish, when its other VAR_OUTPUTs hold the result. DONE is the block's own and no part of the function's signature: the result's fields are the other VAR_OUTPUTs, and none of them can be named DONE. The block declares it, a BOOL in VAR_OUTPUT.

```iecst
{extern async 'wasi:clocks/monotonic-clock@0.3.0' 'wait-for'}
FUNCTION_BLOCK WAIT_FOR
VAR_INPUT how_long : LTIME; END_VAR
END_FUNCTION_BLOCK
```
