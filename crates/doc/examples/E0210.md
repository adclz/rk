---
title: Edge input in a stateless POU
---
`R_EDGE` and `F_EDGE` compare an input with its value at the previous call. Only the instance of a FUNCTION_BLOCK or a PROGRAM keeps that value between calls.

In a FUNCTION or a METHOD, use an `R_TRIG` or an `F_TRIG` from `Std.Edge`.

```iecst
FUNCTION Started : BOOL
VAR_INPUT
    start : BOOL R_EDGE;
END_VAR
    Started := start;
END_FUNCTION
```
