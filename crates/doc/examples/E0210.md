---
title: Edge input in a stateless POU
---
`R_EDGE` and `F_EDGE` compare an input with its value at the previous call. A FUNCTION or METHOD keeps nothing from one call to the next, so only an input of a FUNCTION_BLOCK or a PROGRAM detects an edge.

An `R_TRIG` or an `F_TRIG` from `Std.Edge` detects one anywhere.

```iecst
FUNCTION Started : BOOL
VAR_INPUT
    start : BOOL R_EDGE;
END_VAR
    Started := start;
END_FUNCTION
```
