---
title: Unknown pragma
---
rk knows eight pragmas: `{test}`, `{once}`, `{export}`, `{warn}`, `{info}`, `{allow}`, `{extern}` and `{wasm}`. Any other text in braces is refused, wherever it stands.

An attribute copied from another toolchain is not ignored, because some of them change what the code means. Remove it, or write in rk what it was for.

```iecst
FUNCTION_BLOCK Motor
VAR
    {attribute 'hide'}
    speed : INT;
END_VAR
END_FUNCTION_BLOCK
```
