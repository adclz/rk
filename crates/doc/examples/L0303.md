---
title: Missing input parameter
lint_rule: missing-input-param
---
A FUNCTION_BLOCK or PROGRAM call leaves out a VAR_INPUT, which keeps its previous value.

It is legal, but usually an oversight. In a FUNCTION call it is E0802.

```iecst
FUNCTION_BLOCK ramp
VAR_INPUT
    target : INT;
    rate : INT;
END_VAR
VAR_OUTPUT
    value : INT;
END_VAR
    value := target;
END_FUNCTION_BLOCK

FUNCTION_BLOCK caller
VAR
    r : ramp;
END_VAR
    r(target := 100);
END_FUNCTION_BLOCK
```
