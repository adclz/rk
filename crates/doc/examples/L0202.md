---
title: Variable shadows POU
lint_rule: shadowing-variable
---
A variable name shadows a POU (function, function block, class, etc.) available in scope.

```iecst
FUNCTION_BLOCK PrintLog
END_FUNCTION_BLOCK
```

```iecst
FUNCTION test : INT
VAR
    PrintLog : BOOL;
END_VAR
    PrintLog := TRUE;
    test := 0;
END_FUNCTION
```
