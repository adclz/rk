---
title: Qualifier on a VAR_IN_OUT bound by reference
---
`RETAIN` and `NON_RETAIN` say what an instance keeps of a member. A `FUNCTION_BLOCK` keeps a `VAR_IN_OUT` of a scalar type as a member, so its section takes the qualifier. A `STRING`, a reference or an aggregate is bound to the caller's variable at each call, and the instance keeps nothing of it. Drop the qualifier.

```iecst
TYPE Pt : STRUCT x : INT; y : INT; END_STRUCT; END_TYPE

FUNCTION_BLOCK fb1
VAR_IN_OUT RETAIN
    p : Pt;
END_VAR
    p.x := p.x + 1;
END_FUNCTION_BLOCK
```
