---
title: Exact comparison of time values
lint_rule: time-equality
---
A TIME, a TIME_OF_DAY or a DATE_AND_TIME is compared with `=` or `<>` against a constant.

A time read at each scan moves by a whole scan: with a 10 ms task, a timer's `ET` can go from 4.998 s to 5.008 s and never be `T#5S`.
`ET = T#5S` then stays FALSE.
Compare with `>=` or `<=`, which holds once the time has reached the value.

Two variables compared are not reported, since `pt <> last_pt` is how a program sees a setting change.
Nor is a zero duration, which a timer's `ET` holds exactly before it starts, nor a DATE, which counts whole days.

```iecst
FUNCTION_BLOCK Dosing
VAR_INPUT
    elapsed : TIME;
END_VAR
VAR_OUTPUT
    done : BOOL;
END_VAR
    IF elapsed = T#5S THEN
        done := TRUE;
    END_IF;
END_FUNCTION_BLOCK
```
