---
title: Exact comparison of time values
lint_rule: time-equality
---
A TIME, TIME_OF_DAY or DATE_AND_TIME is compared with `=` or `<>` against a constant.

A program sees the time once per scan.
With a 10 ms task, a timer's `ET` can go from 4.998 s to 5.008 s without ever being `T#5S`.
Compare with `>=` or `<=` to catch the moment the time gets there.

The rule leaves these alone:

- **Two variables**, as in `pt <> last_pt`, the usual test for a changed setting.
- **A zero duration**, which a timer's `ET` holds before it starts.
- **A DATE**, which only counts days.

```iecst
FUNCTION_BLOCK Dosing
VAR_INPUT
    elapsed : TIME;
END_VAR
VAR_OUTPUT
    done : BOOL;
END_VAR
    IF elapsed = T#5S THEN
        done := TRUE;
    END_IF;
END_FUNCTION_BLOCK
```
