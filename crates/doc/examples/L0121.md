---
title: Latin-1 escape in a STRING
lint_rule: latin1-escape
---
A STRING literal holds a `$hh` escape of $80 or more that is not part of UTF-8 text.

A `$hh` is one byte, and a STRING is UTF-8. Code written for Latin-1 uses `$E9` for `é`, but in UTF-8 `é` is `$C3$A9`, so `'caf$E9' = 'café'` is FALSE. Write the character itself, or its UTF-8 bytes. A CHAR is a code point, so `CHAR#'$E9'` is `é` and is not reported.

```iecst
FUNCTION Greet : INT
VAR s : STRING; END_VAR
    s := 'caf$E9';
    Greet := 0;
END_FUNCTION
```
