---
title: Types contain each other
---
Two or more types contain each other by value, around a cycle, so none of them has a finite size.

A member held by address, a VAR_IN_OUT or a REF_TO, is no part of the type and makes no cycle.

```iecst
TYPE a : STRUCT
    field1 : b;
END_STRUCT
END_TYPE

TYPE b : STRUCT
    field1 : a;
END_STRUCT
END_TYPE
```
