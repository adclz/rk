---
title: Method parameter count mismatch
---
A method implementing an interface prototype or overriding a base method declares a different number of parameters. Parameters are matched by position; their names (E1128), sections (E1129) and types (E1126) and the return type (E1127) are checked one by one.

```iecst
CLASS Base
    METHOD PUBLIC myMethod : INT
        VAR_INPUT a : INT; END_VAR
    END_METHOD
END_CLASS

CLASS Derived EXTENDS Base
    METHOD PUBLIC OVERRIDE myMethod : INT
        VAR_INPUT a : INT; b : INT; END_VAR
    END_METHOD
END_CLASS
```
