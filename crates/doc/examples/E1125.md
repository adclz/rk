---
title: Method parameter count mismatch
---
A method declares another number of parameters than the method it implements or overrides.

Parameters are matched by position.

```iecst
CLASS Base
    METHOD PUBLIC myMethod : INT
        VAR_INPUT a : INT; END_VAR
    END_METHOD
END_CLASS

CLASS Derived EXTENDS Base
    METHOD PUBLIC OVERRIDE myMethod : INT
        VAR_INPUT a : INT; b : INT; END_VAR
    END_METHOD
END_CLASS
```
