---
title: Instance in a stateless POU
lint_rule: instance-in-function
---
A FUNCTION or METHOD holds or returns a FUNCTION_BLOCK or CLASS instance, which starts over at every call: a timer in it never expires.

Hold it in a FUNCTION_BLOCK or PROGRAM and pass it as a VAR_IN_OUT. A `{test}` FUNCTION may hold one.

```iecst
FUNCTION_BLOCK Counter
VAR n : INT; END_VAR
    n := n + 1;
END_FUNCTION_BLOCK

FUNCTION tick : INT
VAR c : Counter; END_VAR
    c();
    tick := c.n;
END_FUNCTION
```
