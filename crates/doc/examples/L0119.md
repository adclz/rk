---
title: Instance in a stateless POU
lint_rule: instance-in-function
---
A FUNCTION or METHOD holds or returns a FUNCTION_BLOCK or CLASS instance. FUNCTIONs and METHODs are stateless: an instance one holds starts over at every call, so a timer in it never expires, and one it returns is made afresh by each call.

Hold the instance in a FUNCTION_BLOCK or PROGRAM, and pass it as a `VAR_IN_OUT` where a FUNCTION needs it. A `{test}` FUNCTION may hold one: the runner calls it once.

```iecst
FUNCTION_BLOCK Counter
VAR n : INT; END_VAR
    n := n + 1;
END_FUNCTION_BLOCK

FUNCTION tick : INT
VAR c : Counter; END_VAR
    c();
    tick := c.n;
END_FUNCTION
```
