---
title: Private function called from outside its namespace
---
A FUNCTION declared PRIVATE is callable only from its own namespace, nested namespaces included, on its own side of the library line.
An extension: the standard gives a FUNCTION no access specifier.

```iecst
NAMESPACE Lib
    FUNCTION PRIVATE helper : INT
        helper := 1;
    END_FUNCTION
END_NAMESPACE

NAMESPACE App
    FUNCTION use : INT
        use := Lib.helper();
    END_FUNCTION
END_NAMESPACE
```
