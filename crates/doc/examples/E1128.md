---
title: Method parameter name mismatch
---
A parameter has another name than the one at the same position in the method it implements or overrides. A call by name would reach another parameter.

```iecst
INTERFACE I
    METHOD M : INT
        VAR_INPUT a : INT; END_VAR
    END_METHOD
END_INTERFACE

CLASS C IMPLEMENTS I
    METHOD M : INT
        VAR_INPUT b : INT; END_VAR
        M := b;
    END_METHOD
END_CLASS
```
