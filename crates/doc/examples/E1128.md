---
title: Method parameter name mismatch
---
A parameter of a method implementing an interface prototype or overriding a base method has a different name than the parameter at the same position in the base. Parameters are matched by position, and a caller binding a name through the base signature must reach the same parameter in the implementation.

```iecst
INTERFACE I
    METHOD M : INT
        VAR_INPUT a : INT; END_VAR
    END_METHOD
END_INTERFACE

CLASS C IMPLEMENTS I
    METHOD M : INT
        VAR_INPUT b : INT; END_VAR
        M := b;
    END_METHOD
END_CLASS
```
