---
title: Method parameter default mismatch
---
An input has another default than in the method it implements or overrides.

A call passes the default of the method it names. Through the base, or through an INTERFACE, the implementation's own default would not apply: give both the same default.

```iecst
INTERFACE IScale
    METHOD Scale : INT
        VAR_INPUT k : INT := 1; END_VAR
    END_METHOD
END_INTERFACE

FUNCTION_BLOCK Doubler IMPLEMENTS IScale
    METHOD PUBLIC Scale : INT
        VAR_INPUT k : INT := 2; END_VAR
        Scale := k * 10;
    END_METHOD
END_FUNCTION_BLOCK
```
