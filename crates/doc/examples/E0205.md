---
title: Ambiguous name
---
Several items of this name are in scope, and the compiler cannot tell which one is meant. Qualify the name.

```iecst
NAMESPACE ns1
    FUNCTION SharedName : INT
        SharedName := 0;
    END_FUNCTION
END_NAMESPACE

NAMESPACE ns2
    FUNCTION SharedName : INT
        SharedName := 0;
    END_FUNCTION
END_NAMESPACE

FUNCTION test : INT
    USING ns1;
    USING ns2;
    test := SharedName();
END_FUNCTION
```
