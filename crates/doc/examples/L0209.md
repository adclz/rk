---
title: CASE without ELSE
lint_rule: case-without-else
---
A CASE statement has no ELSE branch: an unlisted value runs nothing.

Labels that take every value the selector can hold need no ELSE: each variant of an enum, or the whole range of an integer or a subrange.
On an enum, the report names the variants no label takes.

```iecst
FUNCTION test : INT
VAR
    x : INT;
END_VAR
    CASE x OF
        1: test := 1;
        2: test := 2;
    END_CASE;
END_FUNCTION
```
