---
title: Interface nested in an aggregate
---
An interface cannot be inside an ARRAY, a REF_TO or a STRUCT: the aggregate would store values of different types.

```iecst
INTERFACE ITF1
    METHOD DoWork END_METHOD
END_INTERFACE

PROGRAM Main
    VAR
        arr : ARRAY[0..2] OF ITF1;
    END_VAR
END_PROGRAM
```
