---
title: Interface not allowed nested in an aggregate
---
An interface may not be nested inside an array, reference, or struct (e.g. `ARRAY OF ITF1`, `REF_TO ITF1`, or a struct field).

Such a placement is stored, heterogeneous state that cannot be monomorphized.

```iecst
INTERFACE ITF1
    METHOD DoWork END_METHOD
END_INTERFACE

PROGRAM Main
    VAR
        arr : ARRAY[0..2] OF ITF1;
    END_VAR
END_PROGRAM
```
