---
title: Method parameter section mismatch
---
A parameter is in another section (VAR_INPUT, VAR_OUTPUT, VAR_IN_OUT) than in the method it implements or overrides.

The section decides how the argument is passed.

```iecst
INTERFACE I
    METHOD M : INT
        VAR_INPUT a : INT; END_VAR
    END_METHOD
END_INTERFACE

CLASS C IMPLEMENTS I
    METHOD M : INT
        VAR_IN_OUT a : INT; END_VAR
        M := a;
    END_METHOD
END_CLASS
```
