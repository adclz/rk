---
title: Operator not supported by the type
---
The type has no such operator: `+` or `-` on a BOOL, `=` on a STRUCT, an ARRAY or an instance.
A reference has only `=` and `<>`, since `r1 < r2` would compare where two variables happen to sit in memory.
A compound assignment is reported with its operator as written, `on += TRUE` with `+=`. BOOLs have no quotient, so in `ne := on /= off` the `/=` most likely meant `<>`, which is the fix.

Two types that each have the operator but do not convert to each other are E0302.

```iecst
PROGRAM A
    VAR
        b: BOOL;
    END_VAR
    b := b + b;
END_PROGRAM
```
