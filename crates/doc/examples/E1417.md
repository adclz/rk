---
title: Address cannot be located
---
A directly represented variable (`%IX0.0`, `%QW4`) is storage in one of three bands: `%I`, `%Q` or `%M`. Written bare in a body, or bound to a `VAR_GLOBAL` with `AT`, it is stored there, as part of a wider address when the program also names one.

Three kinds of address cannot be:

- An `AT` clause on a POU's own variable. Its storage is a field of the instance, which is laid out as one unit, so it cannot also sit in a band the host copies whole. Declare it as a `VAR_GLOBAL` of the CONFIGURATION and name it from the POU.
- A partly specified address, `%I*`. Its binding comes from `VAR_CONFIG`, which is checked but not applied yet (E1416). Write the address in full.
- An address with no area letter or no width letter, such as `%Z0` or `%I1`.

```iecst
PROGRAM pgm
VAR
    VALVE_POS AT %QW28 : INT;
END_VAR
END_PROGRAM
```
