---
title: Direct variable access is not supported
---
A directly represented variable (`%IX0.0`, `%QW4`) names a location in a process image.

The address is understood — the width letter `X`/`B`/`W`/`D`/`L` gives it its type — but nothing connects it to real I/O yet, so it cannot be compiled.

It is refused here rather than in codegen, where it would surface as an internal compiler error on source that `rk check` called clean.

```iecst
FUNCTION_BLOCK fb1
VAR test : BOOL; END_VAR
    test := %IX0.0;
END_FUNCTION_BLOCK
```
