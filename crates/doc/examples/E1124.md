---
title: Assignment to an interface parameter
---
An interface `VAR_IN_OUT` parameter is a fixed binding to the concrete type passed by the caller.

Reassigning it would break monomorphization (the body is specialized to one concrete type), so it can be used — methods called, passed on — but not reassigned.

```iecst
INTERFACE ITF1
    METHOD DoWork END_METHOD
END_INTERFACE

FUNCTION_BLOCK Impl IMPLEMENTS ITF1
    METHOD DoWork END_METHOD
END_FUNCTION_BLOCK

FUNCTION Use : INT
    VAR_IN_OUT dev : ITF1; END_VAR
    VAR other : Impl; END_VAR
    dev := other;
END_FUNCTION
```
