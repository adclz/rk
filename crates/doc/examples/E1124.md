---
title: Assignment to an interface parameter
---
An interface parameter, `VAR_INPUT` or `VAR_IN_OUT`, stays bound to what the caller passed and cannot be assigned. Call its methods, or pass it on.

```iecst
INTERFACE ITF1
    METHOD DoWork END_METHOD
END_INTERFACE

FUNCTION_BLOCK Impl IMPLEMENTS ITF1
    METHOD DoWork END_METHOD
END_FUNCTION_BLOCK

FUNCTION Use : INT
    VAR_IN_OUT dev : ITF1; END_VAR
    VAR other : Impl; END_VAR
    dev := other;
END_FUNCTION
```
