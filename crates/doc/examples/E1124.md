---
title: Assignment to an interface parameter
---
An interface `VAR_IN_OUT` stays bound to what the caller passed: call its methods or pass it on, but do not assign it.

```iecst
INTERFACE ITF1
    METHOD DoWork END_METHOD
END_INTERFACE

FUNCTION_BLOCK Impl IMPLEMENTS ITF1
    METHOD DoWork END_METHOD
END_FUNCTION_BLOCK

FUNCTION Use : INT
    VAR_IN_OUT dev : ITF1; END_VAR
    VAR other : Impl; END_VAR
    dev := other;
END_FUNCTION
```
