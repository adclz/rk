---
title: Initializer for a member that takes none
---
An instance initializer, `d : Drive := (k := 4)`, sets the members that hold a value of their own.

A VAR_IN_OUT bound by reference, a `STRING` or an aggregate, is given in the call, a VAR_TEMP or a CONSTANT in its declaration, a VAR_EXTERNAL on its global. A `FUNCTION_BLOCK` keeps a VAR_IN_OUT of a scalar type as a member, which takes one.

```iecst
FUNCTION_BLOCK Drive
VAR_IN_OUT name : STRING; END_VAR
VAR k : INT; END_VAR
    IF name = '' THEN k := 1; END_IF;
END_FUNCTION_BLOCK

PROGRAM P
VAR d : Drive := (name := 'pump'); END_VAR
END_PROGRAM
```
