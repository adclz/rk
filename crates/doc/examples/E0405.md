---
title: VAR_IN_OUT given an initial value
---
A `VAR_IN_OUT` is bound to its argument by each call, so it has no value of its own for an instance's initializer to give. Pass the variable in the call instead.

```iecst
FUNCTION_BLOCK Drive
VAR_IN_OUT io : INT; END_VAR
VAR k : INT; END_VAR
    k := io;
END_FUNCTION_BLOCK

PROGRAM P
VAR d : Drive := (io := 30); END_VAR
END_PROGRAM
```
