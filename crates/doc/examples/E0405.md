---
title: Member cannot be initialized
---
An instance's initializer, such as `d : Drive := (k := 4)`, gives values to the members the instance holds. It cannot name a member that has no value of its own for it to give:

- a `VAR_IN_OUT`, which each call binds to its argument. Pass the variable in the call instead;
- a `VAR_TEMP`, which each call makes afresh. Give the value in its declaration, which applies at every call;
- a `VAR_EXTERNAL`, which names a `VAR_GLOBAL`. Give the value in the global's declaration;
- a `CONSTANT`, whose value is its declaration's.

```iecst
FUNCTION_BLOCK Drive
VAR_IN_OUT io : INT; END_VAR
VAR k : INT; END_VAR
    k := io;
END_FUNCTION_BLOCK

PROGRAM P
VAR d : Drive := (io := 30); END_VAR
END_PROGRAM
```
