---
title: Value without a member name
---
An instance initializer, `d : Drive := (speed := 100)`, sets the members it names.

A STRUCT's fields may take their values in the order they are declared, but an instance's members are named. A value written without a name has no member to go to.

```iecst
FUNCTION_BLOCK Drive
VAR_INPUT
    speed : INT;
    ramp : INT;
END_VAR
END_FUNCTION_BLOCK

PROGRAM P
VAR
    d : Drive := (100, 5);
END_VAR
    d();
END_PROGRAM
```
