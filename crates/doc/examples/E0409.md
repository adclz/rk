---
title: Value without a field name
---
An initializer in parentheses gives each field of a STRUCT, or each member of an instance, after its name: `(x := 1, y := 2)`.

A value written without a name has no field to go to.

```iecst
TYPE
    Point : STRUCT
        x : INT;
        y : INT;
    END_STRUCT;
END_TYPE

PROGRAM P
VAR
    p : Point := (1, 2);
END_VAR
    p.x := p.y;
END_PROGRAM
```
