---
title: Chain of assignments outside a statement
---
A chain of assignments, `a := b := 0;`, is a statement of its own. In a call's argument or at the start of a `FOR`, a second `:=` is refused: assign the place in a statement before.

```iecst
FUNCTION Twice : INT
VAR_INPUT v : INT; END_VAR
    Twice := v * 2;
END_FUNCTION

FUNCTION Use : INT
VAR i, first, k, n : INT; END_VAR
    FOR i := first := 1 TO 10 DO
        n := n + Twice(v := k := 3);
    END_FOR;
    Use := n;
END_FUNCTION
```
