---
title: Variable not located
---
Each instance of a variable declared `AT %I*`, `%Q*` or `%M*` needs its address in `VAR_CONFIG`, by a path such as `Res.P1.d.level`.

Hold the instance in a PROGRAM, or in a function block the PROGRAM holds: an array element, a STRUCT field, a global, a VAR_TEMP, a VAR_INPUT or a function's variable has no such path.

```iecst
FUNCTION_BLOCK Drive
VAR
    level AT %I* : INT;
END_VAR
END_FUNCTION_BLOCK

PROGRAM P
VAR d : Drive; END_VAR
END_PROGRAM

CONFIGURATION Cfg
    RESOURCE Res ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
