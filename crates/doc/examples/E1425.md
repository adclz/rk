---
title: Variable not located
---
A variable declared `AT %I*`, `%Q*` or `%M*` leaves its address to the configuration: each instance of its PROGRAM or function block is given one in `VAR_CONFIG`, with a path such as `Res.P1.d.level`.

It is an error when an instance is not given one, and when an instance is held where no path can name it: an element of an array, a field of a STRUCT, a `VAR_GLOBAL`, a `VAR_TEMP`, or a function's variable. Hold the instance in a PROGRAM, or in a function block the PROGRAM holds, and locate it there.

A `VAR_INPUT` is refused too: each call copies its argument over it, and the variable would point wherever the argument's does. Pass the instance as a `VAR_IN_OUT` instead.

```iecst
FUNCTION_BLOCK Drive
VAR
    level AT %I* : INT;
END_VAR
END_FUNCTION_BLOCK

PROGRAM P
VAR d : Drive; END_VAR
END_PROGRAM

CONFIGURATION Cfg
    RESOURCE Res ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
