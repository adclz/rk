---
title: VAR_GLOBAL not allowed in this context
---
`VAR_GLOBAL` can only be used inside a CONFIGURATION.
Global data is application-scoped: a POU reaches it with `VAR_EXTERNAL`, and a RESOURCE holds no variables of its own.

```iecst
FUNCTION_BLOCK fb1
    VAR_GLOBAL

    END_VAR
END_FUNCTION_BLOCK
```
