---
title: VAR_EXTERNAL without a VAR_GLOBAL
---
A `VAR_EXTERNAL` names a global that no `VAR_GLOBAL` declares.

```iecst
PROGRAM prog1
VAR_EXTERNAL
    missing_global : INT;
END_VAR
END_PROGRAM

CONFIGURATION config1
    RESOURCE res1 ON CPU
        TASK task1(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM inst1 WITH task1 : prog1;
    END_RESOURCE
END_CONFIGURATION
```
