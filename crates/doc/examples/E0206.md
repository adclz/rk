---
title: External variable not found
---
A `VAR_EXTERNAL` declaration references a name not present in any accessible `VAR_GLOBAL`.

```iecst
PROGRAM prog1
VAR_EXTERNAL
    missing_global : INT;
END_VAR
END_PROGRAM

CONFIGURATION config1
    RESOURCE res1 ON CPU
        TASK task1(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM inst1 WITH task1 : prog1;
    END_RESOURCE
END_CONFIGURATION
```
