---
title: __CATCH, __FINALLY or __END_TRY without a __TRY
---
`__CATCH`, `__FINALLY` and `__END_TRY` are only accepted inside a `__TRY`.

This happens when the `__TRY` line is missing, or when an `__END_TRY` above already closed it.

```iecst
FUNCTION f1 : INT
    f1 := 1;
    __CATCH
        f1 := 2;
END_FUNCTION
```
