---
title: Name written in another case
lint_rule: name-case
---
A name is written in another case than where it is declared, like `motorspeed` for `MotorSpeed`.

Names ignore case: `motorspeed` and `MotorSpeed` are the same variable to the compiler.
To a reader they look like two different names.
A text search that matches case, in an editor or with `grep`, also finds only one of them.

```iecst
PROGRAM Line
VAR
    MotorSpeed : INT;
END_VAR
    motorspeed := 10;
END_PROGRAM
```
