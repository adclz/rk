---
title: FOR control variable read after the loop
lint_rule: loop-var-after-loop
---
A FOR loop's control variable is read after the loop, before anything writes it again.

IEC 61131-3 does not define what a FOR loop leaves in its counter.
In rk it depends on how the loop ended:

- **At its end:** one step past the last value the body saw, 11 after `FOR i := 1 TO 10`.
- **At the edge of the counter's type or subrange:** the last value, 127 after `FOR s := 120 TO 127` on a SINT.
- **By EXIT:** the value it was at.
- **Without a single pass:** the start value.

Keep the value you need in a variable of its own, set inside the loop.
A WHILE loop is the other way out, since your code steps its counter.

The rule follows every path through the body and reports the first read on each.
A read at the top of an outer loop counts too, when an inner loop further down set the counter on the previous pass.

```iecst
FUNCTION FindKey : INT
VAR_INPUT
    words : ARRAY[0..9] OF STRING;
END_VAR
VAR
    i : INT;
END_VAR
    FOR i := 0 TO 9 DO
        IF words[i] = 'Key' THEN
            EXIT;
        END_IF;
    END_FOR;
    FindKey := i;
END_FUNCTION
```
