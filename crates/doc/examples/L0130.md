---
title: FOR control variable read after the loop
lint_rule: loop-var-after-loop
---
A FOR loop's control variable is read after the loop, before anything writes it again.

IEC 61131-3 leaves the value a FOR loop leaves in its counter to the implementation, and rk's depends on how the loop ended:

- **A loop that runs to its end** leaves the counter one step past the last value the body saw: 11 after `FOR i := 1 TO 10`.
- **One whose next step would leave the counter's type or subrange** leaves the last value instead: 127 after `FOR s := 120 TO 127` on a SINT.
- **One left by EXIT** leaves the value it was at.
- **One that runs no pass** leaves the start value.

Copy the value the program needs into a variable of its own inside the loop, or count with a WHILE loop, whose counter the program steps itself.

Every path is followed: the first read a path reaches from the loop, with the counter as the loop left it, is reported.
A read at the top of an outer loop's body is reported too, when an inner loop further down left the counter on the pass before.

```iecst
FUNCTION FindKey : INT
VAR_INPUT
    words : ARRAY[0..9] OF STRING;
END_VAR
VAR
    i : INT;
END_VAR
    FOR i := 0 TO 9 DO
        IF words[i] = 'Key' THEN
            EXIT;
        END_IF;
    END_FOR;
    FindKey := i;
END_FUNCTION
```
