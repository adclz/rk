---
title: VAR_TEMP not allowed in this context
---
`VAR_TEMP` declares the per-call variables of a FUNCTION, FUNCTION_BLOCK, PROGRAM or METHOD. A CLASS, an INTERFACE prototype and a CONFIGURATION have no code to run, so they have no use for one.

```iecst
CLASS c1
    VAR_TEMP

    END_VAR
END_CLASS
```
