---
title: Extern pragma outside a FUNCTION or FUNCTION_BLOCK
---
Only a FUNCTION, a host's function, or a FUNCTION_BLOCK, a host's async function, can be `{extern}`.

A FUNCTION_BLOCK's pragma says `async`, `{extern async 'module' 'name'}`, and a FUNCTION's does not: an async call is held by the block's instance from one scan to the next.

Wrap the import in a FUNCTION or a FUNCTION_BLOCK, and call it from the PROGRAM.

```iecst
{extern 'host' 'run'}
PROGRAM Main
VAR n : INT; END_VAR
END_PROGRAM
```
