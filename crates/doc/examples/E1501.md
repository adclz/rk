---
title: Extern pragma outside a FUNCTION or FUNCTION_BLOCK
---
Only a FUNCTION, a host's function, or a FUNCTION_BLOCK, what a scan does not wait for, can be `{extern}`: the call of an `async func`, a stream's read or write, or a future's read.

A FUNCTION_BLOCK's pragma says `async`, `{extern async 'module' 'name'}`, and a FUNCTION's does not: the import is lowered async, as the component model's `[async-lower]` prefix says, so its call returns at once, and the block's instance holds what it started from one scan to the next, until `DONE`.

Wrap the import in a FUNCTION or a FUNCTION_BLOCK, and call it from the PROGRAM.

```iecst
{extern 'host' 'run'}
PROGRAM Main
VAR n : INT; END_VAR
END_PROGRAM
```
