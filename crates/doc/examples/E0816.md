---
title: Variadic parameter used outside a fold
---
A variadic parameter stands for as many parameters as the call passed.

Only a fold reads them: `...values+` adds them, `...values=` compares them. The parameter has no value of its own to read, write or pass on.

```iecst
FUNCTION first : INT
    VAR_INPUT
        values : INT...;
    END_VAR
    first := values;
END_FUNCTION
```
