---
title: Variadic parameter used outside a fold
---
A variadic parameter is as many parameters as the call passed, which only a fold reads: `...values+` adds them, `...values=` compares them. Read, written or passed as a whole, it is nothing.

```iecst
FUNCTION first : INT
    VAR_INPUT
        values : INT...;
    END_VAR
    first := values;
END_FUNCTION
```
