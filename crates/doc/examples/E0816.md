---
title: Variadic parameter used as a variable
---
A variadic parameter stands for as many parameters as the call passed.

Only `...` reads them: `...values[0]` reads the first, `...values+` adds them, `...values=` compares them. The parameter has no value of its own to read, write or pass on.

```iecst
FUNCTION first : INT
    VAR_INPUT
        values : INT...;
    END_VAR
    first := values;
END_FUNCTION
```
