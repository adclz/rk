---
title: Initial value is not constant
---
A TYPE default, a member default, a PROGRAM field and a VAR_GLOBAL are set before the program runs, so their value is a constant.

A named CONSTANT works. A FUNCTION's locals may compute theirs, since they start again at every call. An input's default is a constant too: the caller passes it for an omitted argument, before the callee's own variables exist.

A CONSTANT is one value for every instance and every call, so a `REF()` in it names a global.

```iecst
FUNCTION_BLOCK fb
VAR
    m : DINT := some_global;
END_VAR
END_FUNCTION_BLOCK

CONFIGURATION Cfg
VAR_GLOBAL
    some_global : DINT := 5;
END_VAR
    RESOURCE Res ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : Dummy;
    END_RESOURCE
END_CONFIGURATION

PROGRAM Dummy
VAR t : INT; END_VAR
    t := 0;
END_PROGRAM
```
