---
title: Test FUNCTION with a parameter
---
`rk test` calls a test with no arguments, so a VAR_INPUT, a VAR_OUTPUT or a VAR_IN_OUT has nothing to bind it.

Declare the values in the test's VAR, and call a FUNCTION taking them.

```iecst
{test}
FUNCTION test_sum
VAR_INPUT
    value : INT;
END_VAR
END_FUNCTION
```
