---
title: Test FUNCTION with an ARRAY[*] parameter
---
`rk test` calls a test with no arguments. An `ARRAY[*]` parameter takes its bounds from the array a call passes.

Declare the arrays in the test, and call a FUNCTION taking them.

```iecst
{test}
FUNCTION test_sum
VAR_INPUT
    values : ARRAY[*] OF INT;
END_VAR
END_FUNCTION
```
