---
title: Test with a parameter
---
`rk test` calls a test with no arguments, so a VAR_INPUT or a VAR_IN_OUT has nothing to bind it, nor has a test FUNCTION's VAR_OUTPUT. A test FUNCTION_BLOCK's VAR_OUTPUTs are its instance's, its `DONE` among them.

Declare the values in the test's VAR, and call a FUNCTION taking them.

```iecst
{test}
FUNCTION test_sum
VAR_INPUT
    value : INT;
END_VAR
END_FUNCTION
```
