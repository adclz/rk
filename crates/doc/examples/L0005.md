---
title: Unknown rule name in {allow}
lint_rule: unknown-allow
---
An `{allow 'rule-name'}` pragma names a lint rule that does not exist, so it silences nothing. Rule names are the `[linter.rules]` names, e.g. `input-assignment`.

```iecst
FUNCTION_BLOCK fb
VAR_INPUT x : INT; END_VAR
    {allow 'input-asignment'}
    x := 1;
END_FUNCTION_BLOCK
```
