---
title: Assignment to a FUNCTION or METHOD
---
A FUNCTION or METHOD has no storage. Inside its own body its name is its return value, and nowhere else is there anything to assign.

Call it, and assign what the call returns to a variable.

```iecst
FUNCTION scale : INT
VAR_INPUT x : INT; END_VAR
    scale := x * 2;
END_FUNCTION

PROGRAM P
VAR n : INT; END_VAR
    scale := 5;
    n := scale(x := 2);
END_PROGRAM
```
