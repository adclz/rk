---
title: Assignment to a function block instance
---
A variable whose declared type is callable — a FUNCTION_BLOCK instance, or a name that resolves to a FUNCTION — cannot be the target of an assignment. Instances are called, not copied; pass one as a VAR_IN_OUT parameter, or assign its individual members.

```iecst
FUNCTION_BLOCK fb1
END_FUNCTION_BLOCK

FUNCTION_BLOCK fb2
VAR
    inst : fb1;
END_VAR
    inst := 0;
END_FUNCTION_BLOCK
```
