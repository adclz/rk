---
title: ARRAY[*] read outside its block's body
---
A FUNCTION_BLOCK's `ARRAY[*]` VAR_IN_OUT has the bounds of the array each call binds to it. Only the block's body runs in that call.

A method runs in a call of its own. An initializer runs before any call. Code outside the block reads `fb.values` once the call is over.

Pass the array from the body to an `ARRAY[*]` parameter of the method.

```iecst
FUNCTION_BLOCK Buffer
VAR_IN_OUT
    values : ARRAY[*] OF INT;
END_VAR
METHOD PUBLIC First : INT
    First := values[0];
END_METHOD
END_FUNCTION_BLOCK
```
