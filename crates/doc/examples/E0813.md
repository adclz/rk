---
title: Variadic call without arguments
---
A variadic parameter receives at least one argument.

A fold such as `...args+` has no value over an empty pack.

```iecst
FUNCTION sum_all : INT
    VAR_INPUT
        args: INT...
    END_VAR
    sum_all := ...args+
END_FUNCTION

FUNCTION fn1 : INT
    fn1 := sum_all()
END_FUNCTION
```
