---
title: Variadic call without arguments
---
A variadic parameter must receive at least one argument.
A fold such as `...args+` has no value over an empty pack, so an empty call has nothing to compute.

```iecst
FUNCTION sum_all : INT
    VAR_INPUT
        args: INT...
    END_VAR
    sum_all := ...args+
END_FUNCTION

FUNCTION fn1 : INT
    fn1 := sum_all()
END_FUNCTION
```
