---
title: Interface method implemented without PUBLIC
---
An INTERFACE's methods are public, and so is the method that implements one: a call through the interface reaches it from anywhere. Write `PUBLIC`, or no access specifier; `PRIVATE`, `PROTECTED` and `INTERNAL` are refused.

```iecst
INTERFACE IShow
    METHOD Show : INT END_METHOD
END_INTERFACE

FUNCTION_BLOCK Pump IMPLEMENTS IShow
    METHOD PRIVATE Show : INT
        Show := 7;
    END_METHOD
END_FUNCTION_BLOCK
```
