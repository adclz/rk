---
title: Variable out of reach
---
A variable is named where its storage is not.

A `VAR_TEMP` lives while its own body runs, so a METHOD of the block, a derived block, an instance (`f.tmp`) and `THIS^` cannot name it: give the METHOD or the derived block a `VAR_TEMP` of its own. A `VAR_EXTERNAL` names a global that no instance holds, so `f.g` names nothing: name the global itself. A METHOD's variables live while it runs, so `f.M.x` names nothing either.

```iecst
FUNCTION_BLOCK Fb
VAR_TEMP scratch : INT; END_VAR
    METHOD Peek : INT
        Peek := scratch;
    END_METHOD
END_FUNCTION_BLOCK
```
