---
title: Access to a PROTECTED item
---
A PROTECTED variable or method is reached from its own POU and those derived from it.

```iecst
CLASS Base
    METHOD PROTECTED myProtectedMethod  END_METHOD
END_CLASS

FUNCTION_BLOCK fn1
    VAR
        obj: Base;
    END_VAR
    obj.myProtectedMethod();
END_FUNCTION_BLOCK
```
