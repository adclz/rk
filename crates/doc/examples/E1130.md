title: Base of the wrong kind
---
`EXTENDS` on a FUNCTION_BLOCK names a FUNCTION_BLOCK or a CLASS, and on a CLASS a CLASS: a CLASS has no body to inherit a FUNCTION_BLOCK's. `IMPLEMENTS`, and `EXTENDS` on an INTERFACE, name INTERFACEs.

```iecst
INTERFACE IDrive
    METHOD start : BOOL END_METHOD
END_INTERFACE

FUNCTION_BLOCK Motor EXTENDS IDrive
END_FUNCTION_BLOCK
```
