---
title: Duplicate location
---
Two declarations are bound to the same address.

Declare the address once, and use that variable wherever you need it.

```iecst
PROGRAM P
VAR_EXTERNAL a : INT; b : INT; END_VAR
VAR t : INT; END_VAR
    t := a + b;
END_PROGRAM

CONFIGURATION Cfg
VAR_GLOBAL
    a AT %IW0 : INT;
    b AT %IW0 : INT;
END_VAR
    RESOURCE R ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
