---
title: Duplicate location
---
Two declarations are bound to the same address.

An address is one channel, but each declaration is given storage of its own, so the program would have two variables where the plant has one: a write through one is never seen through the other, and a host binding by address finds it twice.

Declare the channel once and name that variable wherever it is needed.

```iecst
PROGRAM P
VAR_EXTERNAL a : INT; b : INT; END_VAR
VAR t : INT; END_VAR
    t := a + b;
END_PROGRAM

CONFIGURATION Cfg
VAR_GLOBAL
    a AT %IW0 : INT;
    b AT %IW0 : INT;
END_VAR
    RESOURCE R ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
