---
title: VAR_IN_OUT bound with =>
---
The `=>` arrow binds outputs. A VAR_IN_OUT parameter is bound with `:=` - it flows both ways through one variable.

```iecst
FUNCTION bump : INT
VAR_IN_OUT io : INT; END_VAR
    bump := io;
END_FUNCTION

FUNCTION f1 : INT
VAR y : INT; END_VAR
    f1 := bump(io => y);
END_FUNCTION
```
