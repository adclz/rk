---
title: VAR_INPUT or VAR_IN_OUT bound with =>
---
The `=>` arrow binds outputs.

An input takes a value with `:=`. A VAR_IN_OUT is bound with `:=` too: it flows both ways through one variable.

```iecst
FUNCTION bump : INT
VAR_IN_OUT io : INT; END_VAR
    bump := io;
END_FUNCTION

FUNCTION f1 : INT
VAR y : INT; END_VAR
    f1 := bump(io => y);
END_FUNCTION
```

```iecst
FUNCTION twice : INT
VAR_INPUT a : INT; END_VAR
    twice := a * 2;
END_FUNCTION

FUNCTION f2 : INT
VAR y : INT; END_VAR
    f2 := twice(a => y);
END_FUNCTION
```
