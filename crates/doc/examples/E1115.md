---
title: Inherited variable name shadowed
---
The names of the variables in the base and the derived function blocks shall be unique. A derived function block may not redeclare a variable name inherited from a base.

```iecst
FUNCTION_BLOCK base
VAR c : INT; END_VAR
END_FUNCTION_BLOCK

FUNCTION_BLOCK derived EXTENDS base
VAR c : INT; END_VAR
END_FUNCTION_BLOCK
```
