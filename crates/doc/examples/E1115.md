---
title: Inherited variable redeclared
---
A derived FUNCTION_BLOCK cannot redeclare a variable it inherits from its base: the names are unique across both.

```iecst
FUNCTION_BLOCK base
VAR c : INT; END_VAR
END_FUNCTION_BLOCK

FUNCTION_BLOCK derived EXTENDS base
VAR c : INT; END_VAR
END_FUNCTION_BLOCK
```
