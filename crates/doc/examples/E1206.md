---
title: FOR counter is not an integer
---
A FOR loop counts in an integer: SINT, INT, DINT, LINT, an unsigned one of those, or a subrange or alias of one. A BOOL, a REAL, a TIME, a bit string such as BYTE, or an enumeration is not a counter.

```iecst
FUNCTION f : INT
VAR b : BOOL; n : INT; END_VAR
    FOR b := FALSE TO TRUE DO
        n := n + 1;
    END_FOR;
    f := n;
END_FUNCTION
```
