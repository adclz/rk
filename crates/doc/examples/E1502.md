---
title: Not representable on an extern FUNCTION
---
An `{extern}` FUNCTION is a WASM import, and its interface is exactly its declaration: `VAR_INPUT` become the params (copies; aggregates as a pointer to a call-entry snapshot), scalar `VAR_OUTPUT` become the results in declaration order, and the return type is the last result. Three things cannot cross that boundary: `VAR_IN_OUT` (a pointer into caller storage with a mutation contract; an extern takes copies), an aggregate or STRING output (no WASM result type to ride), and statements (the import IS the body).

```iecst
{extern 'host' 'fill'}
FUNCTION fill : INT
VAR_IN_OUT buf : INT; END_VAR
END_FUNCTION
```
