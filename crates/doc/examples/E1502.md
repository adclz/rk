---
title: Not representable on an extern FUNCTION
---
An `{extern}` FUNCTION is a WASM import: its VAR_INPUT are the params, and its VAR_OUTPUT and its return value, last, the fields of the record it returns.

It cannot have a VAR_IN_OUT, a STRUCT, ARRAY, instance, `ARRAY[*]` or variadic input, an aggregate or STRING output or return value, or a body.

An import from a module other than WASI's is typed in WIT. It takes scalars and STRINGs, 16 values at most with a STRING counting two. So it cannot have a `REF_TO` input either.

A WASI import keeps the types WASI's WIT gives it, in their core form: a record comes back in VAR_OUTPUT, one for each of its fields, or through a `REF_TO` input. A STRUCT or an ARRAY input would go as an address into rk's own layout, which no WASI function reads.

```iecst
{extern 'host' 'fill'}
FUNCTION fill : INT
VAR_IN_OUT buf : INT; END_VAR
END_FUNCTION
```
