---
title: Not representable on an extern FUNCTION
---
An `{extern}` FUNCTION is a WASM import: its VAR_INPUT are the params, its return value the result.

It cannot have a VAR_IN_OUT, an `ARRAY[*]` or variadic input, an aggregate or STRING output or return value, or a body.

An import from a module other than WASI's is typed in WIT. It takes scalars and STRINGs, 16 values at most with a STRING counting two, and returns its return value only. So it cannot have a VAR_OUTPUT, a `REF_TO` input, or a STRUCT, ARRAY or instance input.

A WASI import keeps the types WASI's WIT gives it: a record comes back through a `REF_TO` input.

```iecst
{extern 'host' 'fill'}
FUNCTION fill : INT
VAR_IN_OUT buf : INT; END_VAR
END_FUNCTION
```
