---
title: Not representable on an extern FUNCTION
---
An `{extern}` FUNCTION is a WASM import: its VAR_INPUT are the params, its scalar VAR_OUTPUT and return value the results.

It cannot have a VAR_IN_OUT, an `ARRAY[*]` input, an aggregate or STRING output, or a body.

```iecst
{extern 'host' 'fill'}
FUNCTION fill : INT
VAR_IN_OUT buf : INT; END_VAR
END_FUNCTION
```
