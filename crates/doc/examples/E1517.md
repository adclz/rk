---
title: Test FUNCTION_BLOCK without its DONE
---
`rk test` calls a test FUNCTION_BLOCK once per cycle, on an instance of its own, until a cycle leaves its `DONE` TRUE: the test has then passed. A raise fails it in the cycle that raised, and so does the time running out before `DONE`.

The block declares `DONE`, a BOOL in VAR_OUTPUT.

```iecst
{test}
FUNCTION_BLOCK test_pump_starts
VAR
    cycles : INT;
END_VAR
cycles := cycles + 1;
END_FUNCTION_BLOCK
```
