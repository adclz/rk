---
title: FOR control is not a variable
---
A FOR statement's control must be a bare variable name.
A struct field, an array element, a dereference or a bit access cannot be a loop counter.

```iecst
TYPE Rec : STRUCT i : INT; END_STRUCT; END_TYPE

FUNCTION f1 : INT
VAR
    r : Rec;
END_VAR
    FOR r.i := 0 TO 3 DO
        f1 := f1 + 1;
    END_FOR;
END_FUNCTION
```
