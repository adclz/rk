---
title: Task running a FUNCTION_BLOCK instance
lint_rule: task-runs-block
---
The configuration gives a task a FUNCTION_BLOCK instance of a program to run, `fb1 WITH Fast`, instead of a PROGRAM.

The instance then runs at the task's rate, apart from the program that holds it.
Nothing in the program's body shows when it runs.
This association is not recommended.
Call the instance from a PROGRAM the task runs instead.

```iecst
FUNCTION_BLOCK Counter
VAR_OUTPUT
    n : INT;
END_VAR
    n := n + 1;
END_FUNCTION_BLOCK

PROGRAM Line
VAR
    fb1 : Counter;
END_VAR
END_PROGRAM

CONFIGURATION Plant
    RESOURCE Res ON CPU
        TASK Fast(INTERVAL := T#10ms, PRIORITY := 1);
        TASK Slow(INTERVAL := T#20ms, PRIORITY := 2);
        PROGRAM L WITH Slow : Line(fb1 WITH Fast);
    END_RESOURCE
END_CONFIGURATION
```
