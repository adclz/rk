---
title: RETAIN on an I/O location
---
Only `%M` can be `RETAIN`: a restored `%I` or `%Q` would run the first scan on the last power cycle's values.

A variable declared `AT %M*` has no storage of its own: to persist a marker, locate it in full.

```iecst
PROGRAM P
VAR_EXTERNAL sensor : BOOL; END_VAR
VAR seen : BOOL; END_VAR
    seen := sensor;
END_PROGRAM

CONFIGURATION Cfg
VAR_GLOBAL RETAIN sensor AT %IX0.0 : BOOL; END_VAR
    RESOURCE R ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
