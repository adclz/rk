---
title: FOR control variable written
lint_rule: loop-var-modified
---
A FOR loop's control variable is written inside the loop body, so the loop no longer runs the declared number of times.

```iecst
FUNCTION test : INT
VAR
    i : INT;
END_VAR
    FOR i := 0 TO 10 DO
        i := i + 2;
    END_FOR;
END_FUNCTION
```
