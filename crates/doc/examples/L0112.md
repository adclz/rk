---
title: Loop variable modified
lint_rule: loop-var-modified
---
A FOR loop control variable is modified inside the loop body.
This can cause unexpected iteration behavior.

```iecst
FUNCTION test : INT
VAR
    i : INT;
END_VAR
    FOR i := 0 TO 10 DO
        i := i + 2;
    END_FOR;
END_FUNCTION
```
