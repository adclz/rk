---
title: Uninitialized output
lint_rule: uninitialized-output
---
A `VAR_OUTPUT` variable is never assigned in the body.
The instance field is zero-initialized, so this is permitted - but an output the body never writes is usually an unfinished one.

```iecst
FUNCTION_BLOCK counter
VAR_INPUT
    step : INT;
END_VAR
VAR_OUTPUT
    total : INT;
END_VAR
VAR
    n : INT;
END_VAR
    n := n + step;
END_FUNCTION_BLOCK
```
