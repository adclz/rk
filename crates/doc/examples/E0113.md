---
title: Duplicate PROGRAM instance name
---
Two PROGRAM instances in the same configuration have the same name.

```iecst
PROGRAM prog1
END_PROGRAM

CONFIGURATION config1
    RESOURCE res1 ON CPU
        TASK task1(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM inst1 WITH task1 : prog1;
        PROGRAM inst1 WITH task1 : prog1;
    END_RESOURCE
END_CONFIGURATION
```
