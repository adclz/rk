---
title: Reference outlives its storage
---
A reference to a call's own storage leaves the call: a FUNCTION or METHOD returns it, or stores it in an output, a VAR_IN_OUT, an instance member or a global.
The next call reuses that storage, so the reference reads whatever that call leaves there.

A call's own storage is a FUNCTION's or METHOD's VAR, VAR_TEMP and VAR_INPUT, and the VAR_TEMP of a FUNCTION_BLOCK or PROGRAM.
Point the reference at instance state, at a global, or at a VAR_IN_OUT, which the caller owns.

```iecst
TYPE PInt : REF_TO INT; END_TYPE

FUNCTION borrow : PInt
VAR
    local : INT := 1;
END_VAR
    borrow := REF(local);
END_FUNCTION
```
