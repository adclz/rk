---
title: Reference outlives its storage
---
A FUNCTION or METHOD returns a reference to its own local storage, and the next call reuses that storage.

Return a reference to instance state, or to a VAR_IN_OUT.

```iecst
TYPE PInt : REF_TO INT; END_TYPE

FUNCTION borrow : PInt
VAR
    local : INT := 1;
END_VAR
    borrow := REF(local);
END_FUNCTION
```
