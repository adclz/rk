---
title: Exact comparison of REAL values
lint_rule: float-equality
---
Two REAL or LREAL values are compared with `=` or `<>`.

A REAL holds the binary fraction nearest to a decimal, so a computed value is rarely the exact one written: `0.1 + 0.2 = 0.3` is FALSE.
Compare the difference with a tolerance instead, `ABS(a - b) < 1.0E-6`.

A comparison with zero is not reported, nor `x <> x`, which holds for a NaN only.

```iecst
FUNCTION Reached : BOOL
VAR_INPUT
    position : REAL;
    target : REAL;
END_VAR
    Reached := position = target;
END_FUNCTION
```
