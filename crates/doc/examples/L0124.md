---
title: Exact comparison of REAL values
lint_rule: float-equality
---
Two REAL or LREAL values are compared with `=` or `<>`.

A REAL holds the binary fraction nearest to a decimal, so a computed value is rarely the exact one written: `1.1 + 2.2 = 3.3` is FALSE.
If a tolerance is acceptable, compare the difference with one in the values' own unit, `ABS(a - b) <= tolerance`.
A value moving to a target is compared with `>=` or `<=`, since it can step past it.

A comparison with zero is not reported, nor `x <> x`, which holds for a NaN only.

```iecst
FUNCTION Reached : BOOL
VAR_INPUT
    position : REAL;
    target : REAL;
END_VAR
    Reached := position = target;
END_FUNCTION
```
