---
title: Test pragma outside a FUNCTION
---
A {test} pragma is valid only on a FUNCTION, like {extern}: a test is a () entry the runner calls, and a FUNCTION_BLOCK, PROGRAM or METHOD has no such entry. A POU that exists only for tests is hidden with FUNCTION PRIVATE, not marked as a test.

```iecst
{test}
PROGRAM my_test
END_PROGRAM
```
