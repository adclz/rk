---
title: Test pragma outside a FUNCTION or FUNCTION_BLOCK
---
`{test}` is valid on a FUNCTION, which `rk test` calls once, and on a FUNCTION_BLOCK, which it calls cycle by cycle on an instance of its own. An ABSTRACT or `{extern}` FUNCTION_BLOCK has no instance it can make.

A POU that only tests use is hidden with FUNCTION PRIVATE.

```iecst
{test}
PROGRAM my_test
END_PROGRAM
```
