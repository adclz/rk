---
title: Unused POU
lint_rule: unused-pou
---
A FUNCTION, FUNCTION_BLOCK, CLASS or PROGRAM is declared but never reached by what the application runs.

The application starts from what the configuration runs, from the FUNCTIONs it exports and from the tests.
A POU is reached when a reached POU calls it, declares a variable of its type, or extends or implements it.

The rule reports nothing in a workspace without a CONFIGURATION.
Such a workspace is a library: its POUs are for others to use.

```iecst
FUNCTION Forgotten : INT
    Forgotten := 1;
END_FUNCTION

PROGRAM Main
END_PROGRAM

CONFIGURATION Plant
    RESOURCE Res ON CPU
        TASK Fast(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM M WITH Fast : Main;
    END_RESOURCE
END_CONFIGURATION
```
