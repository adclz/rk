---
title: Output written by several program instances
lint_rule: double-writer
---
An output location, `%Q`, is written by more than one program instance of the configuration.
At each scan the last instance to run sets the output, and what the others wrote is lost before the host reads it.

The writes count wherever they are: in the program's body, or in a FUNCTION, METHOD or FUNCTION_BLOCK it calls.
A program with a located output instantiated twice writes the same address twice.

Write the output in one program, and send it the others' requests through a variable.

```iecst
PROGRAM Filling
VAR_EXTERNAL
    valve : BOOL;
END_VAR
    valve := TRUE;
END_PROGRAM

PROGRAM Draining
VAR_EXTERNAL
    valve : BOOL;
END_VAR
    valve := FALSE;
END_PROGRAM

CONFIGURATION Plant
VAR_GLOBAL
    valve AT %QX0.0 : BOOL;
END_VAR
    RESOURCE Main ON CPU
        TASK Fast(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM Fill WITH Fast : Filling;
        PROGRAM Drain WITH Fast : Draining;
    END_RESOURCE
END_CONFIGURATION
```
