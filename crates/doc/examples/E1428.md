---
title: Program configuration element refused
---
An element of a program's list, like `F(x1 := %IX0.0, y1 => total, fb1 WITH FAST)`, does not hold.

`:=` feeds an input from a global of the same type, an address as wide or a constant, and `=>` copies an output to a global or an address. `fb WITH task` names a function block instance of the program and a task of the resource.

```iecst
PROGRAM F
VAR_INPUT x1 : BOOL; END_VAR
VAR_OUTPUT y1 : INT; END_VAR
    IF x1 THEN y1 := y1 + 1; END_IF;
END_PROGRAM

CONFIGURATION Cfg
    RESOURCE Res ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : F(y1 := 1);
    END_RESOURCE
END_CONFIGURATION
```
