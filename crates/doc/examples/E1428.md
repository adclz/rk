---
title: Program configuration element refused
---
An element of a program configuration's list, such as `PROGRAM P1 WITH T : F(x1 := %IX0.0, y1 => total, fb1 WITH FAST)`, is refused when it cannot hold. `:=` feeds a `VAR_INPUT` and `=>` copies a `VAR_OUTPUT` out. The other end is a `VAR_GLOBAL` of the same type, an address as wide as the variable, or, for an input, a constant. An input has one source. `fb WITH task` names a `FUNCTION_BLOCK` instance of the program and a `TASK` of the resource, and the task runs that block alone, so the program's body does not call it.

```iecst
PROGRAM F
VAR_INPUT x1 : BOOL; END_VAR
VAR_OUTPUT y1 : INT; END_VAR
    IF x1 THEN y1 := y1 + 1; END_IF;
END_PROGRAM

CONFIGURATION Cfg
    RESOURCE Res ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : F(y1 := 1);
    END_RESOURCE
END_CONFIGURATION
```
