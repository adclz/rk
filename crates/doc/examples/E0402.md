---
title: Function call in a repeat count
---
The repeat count of an array initializer, `[3(x)]`, has to be a constant, and a call is not one.

Elsewhere in an initializer, a call is refused with E0401 where a constant is required, and accepted in the locals of a FUNCTION or METHOD.

```iecst
FUNCTION_BLOCK fb1
VAR
    ml : ARRAY [0..2] OF INT := [1(call(IN := 5, OUT => OUT))];
END_VAR
END_FUNCTION_BLOCK
```
