---
title: FOR step is not a nonzero constant
---
The step sets the loop's direction at compile time, so it is a nonzero constant.

A named CONSTANT and arithmetic over constants work.

```iecst
FUNCTION f1 : INT
VAR i : INT; n : INT; END_VAR
    n := -1;
    FOR i := 5 TO 1 BY n DO
    END_FOR;
END_FUNCTION
```
