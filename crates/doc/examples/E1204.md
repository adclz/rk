---
title: FOR step is not a nonzero constant
---
The step's sign picks the loop's direction when the code is compiled, so the step must evaluate to a constant at compile time — and to a nonzero one, since a step of zero never advances the counter. A CONSTANT variable or folding arithmetic works; an ordinary variable does not.

```iecst
FUNCTION f1 : INT
VAR i : INT; n : INT; END_VAR
    n := -1;
    FOR i := 5 TO 1 BY n DO
    END_FOR;
END_FUNCTION
```
