---
title: FOR step not a nonzero constant
---
The step sets the loop's direction at compile time, so it has to be a nonzero constant. A named CONSTANT and arithmetic over constants are accepted.

```iecst
FUNCTION f1 : INT
VAR i : INT; n : INT; END_VAR
    n := -1;
    FOR i := 5 TO 1 BY n DO
    END_FOR;
END_FUNCTION
```
