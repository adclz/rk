---
title: Negative radix literal
lint_rule: negative-radix-literal
---
An untyped radix literal has its top bit set where a signed integer is expected, so it is negative.

A radix literal is a bit pattern of the width its context gives it: `16#80` is 128 in an INT and -128 in a SINT. Write `SINT#16#80` when the pattern is meant, or use a wider type for 128. A typed literal is not reported. Neither is one under a minus, where it is a number (`-(16#80)` is minus 128), nor an operand of AND, OR or XOR, where its bits are the point.

```iecst
FUNCTION Mask : SINT
VAR m : SINT := 16#80; END_VAR
    Mask := m;
END_FUNCTION
```
