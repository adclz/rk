---
title: Location refused
---
A `VAR_CONFIG` entry with `AT` gives an address to a variable declared `AT %I*`, `%Q*` or `%M*`, one instance at a time. The variable then points at that address.

The entry is refused when:

- the variable is not declared with a partial address, so its address is not the configuration's to give;
- the address is in another area than the declaration's, such as `%QW2` for a variable declared `AT %I*`;
- the address is not complete, or does not name an area and a width;
- the address is not as wide as the variable's type;
- the address is a bit of a wider address the program also names. A bit has no address of its own for the variable to point at.

```iecst
PROGRAM P
VAR level : INT; END_VAR
END_PROGRAM

CONFIGURATION Cfg
VAR_CONFIG
    Res.P1.level AT %IW2 : INT;
END_VAR
    RESOURCE Res ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
