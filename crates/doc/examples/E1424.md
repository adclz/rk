---
title: Location refused
---
A `VAR_CONFIG` entry with `AT` locates a variable declared `AT %I*`, `%Q*` or `%M*`, in one instance.

The address is complete, in the variable's area and as wide as its type, not a bit of a wider address, and given once.

```iecst
PROGRAM P
VAR level : INT; END_VAR
END_PROGRAM

CONFIGURATION Cfg
VAR_CONFIG
    Res.P1.level AT %IW2 : INT;
END_VAR
    RESOURCE Res ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
