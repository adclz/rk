---
title: Initial value on shared bytes
---
When `config.toml` numbers addresses by byte, two addresses can share bytes with neither holding the other: `%MW7` and `%MW8` share byte 8. An initial value of one would set part of the other, so neither can have one, whether its declaration, its type or a `VAR_CONFIG` entry gives it.

To give them an initial value, locate a variable at an address that holds all their bytes, like `%MD7`, and give it the initial value: the others are then parts of it.

```toml
[addresses]
numbering = "byte"
```

```iecst
PROGRAM P
VAR_EXTERNAL first : WORD; second : WORD; END_VAR
    first := second;
END_PROGRAM

CONFIGURATION C
    VAR_GLOBAL
        first AT %MW7 : WORD := 16#1234;
        second AT %MW8 : WORD;
    END_VAR
    RESOURCE R ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM Main WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
