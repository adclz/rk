---
title: Possibly null dereference
---
A reference is dereferenced where it may still be NULL: it was never set since its declaration, or it was set to NULL.

Guard the dereference. `IF p <> NULL THEN` narrows `p` inside the branch, `IF p = NULL THEN RETURN; END_IF` narrows everything below, and `p := REF(x)` narrows what follows.

A `VAR_INPUT` or `VAR_IN_OUT` reference is trusted: the caller is responsible for it.

```iecst
FUNCTION_BLOCK fb1
VAR
    ptr: REF_TO INT;
    x: INT;
END_VAR
    x := ptr^;
END_FUNCTION_BLOCK
```
