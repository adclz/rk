---
title: Initializer index not constant
---
The index of an element in an array initializer, `[i] := 7`, says where the value goes before the program runs. It is a literal or a named CONSTANT, like a bound.

```iecst
FUNCTION_BLOCK fb1
VAR
    i : INT := 1;
    x : ARRAY[0..3] OF INT := [[i] := 7];
END_VAR
END_FUNCTION_BLOCK
```
