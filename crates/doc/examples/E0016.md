---
title: SUPER after a dot in a path
---
`SUPER` can only start a path, as in `SUPER.m()`: `THIS.SUPER.m()` and `inst.SUPER.x` are refused.

Without an EXTENDS clause the error is E1107, and in a FUNCTION or a PROGRAM it is E1106.

```iecst
FUNCTION_BLOCK base
METHOD m
END_METHOD
END_FUNCTION_BLOCK

FUNCTION_BLOCK derived EXTENDS base
    THIS.SUPER.m();
END_FUNCTION_BLOCK
```
