---
title: Uninitialized output
lint_rule: uninitialized-output
---
A `VAR_OUTPUT` is never written in the body.

It keeps its initial value: its initializer, or the default of its type (0, an enum's first value, a subrange's lower bound). That is legal, but an output the body never writes is usually unfinished.

```iecst
FUNCTION_BLOCK counter
VAR_INPUT
    step : INT;
END_VAR
VAR_OUTPUT
    total : INT;
END_VAR
VAR
    n : INT;
END_VAR
    n := n + step;
END_FUNCTION_BLOCK
```
