---
title: Duplicate configuration
lint_rule: duplicate-configuration
---
Same-named CONFIGURATION blocks merge, which is how VAR_GLOBALs are split across files.
Two in ONE file separate nothing — merge them.

```iecst
CONFIGURATION Plant
    VAR_GLOBAL
        a : INT;
    END_VAR
END_CONFIGURATION

CONFIGURATION Plant
    VAR_GLOBAL
        b : INT;
    END_VAR
END_CONFIGURATION
```
