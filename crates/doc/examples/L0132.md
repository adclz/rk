---
title: Address used in a body
lint_rule: address-in-body
---
A body names an address, like `%IX0.1`, instead of a variable declared at it.

An address says nothing about what is wired there.
Declaring a variable `AT` it, like `start_button AT %IX0.1 : BOOL;`, gives it a name that tells the reader what is wired there.
When the wiring moves, only that declaration changes.

Addresses are not recommended in a body.
The rule leaves out the connections of a program instance in the configuration, such as `Counter(pulse := %IX0.0)`, since they are not in a body.

```iecst
PROGRAM Mixer
    IF %IX0.1 THEN
        %QX0.0 := TRUE;
    END_IF;
END_PROGRAM
```
