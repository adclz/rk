---
title: Address used in a body
lint_rule: address-in-body
---
A body names an address, like `%IX0.1`, instead of a variable declared at it.

The address says nothing of what is wired there, and every body that names it has to change when the wiring moves.
A variable declared `AT` the address names it once, in one place: `start_button AT %IX0.1 : BOOL;`.

IEC 61131-3 marks an address in a body as deprecated.
The connections of a program instance in the configuration, `Counter(pulse := %IX0.0)`, are not in a body and are not reported.

```iecst
PROGRAM Mixer
    IF %IX0.1 THEN
        %QX0.0 := TRUE;
    END_IF;
END_PROGRAM
```
