---
title: This FUNCTION cannot be exported
---
An `{export}` FUNCTION is exported under its name, so it has to be one function with one name.

Five FUNCTIONs are not:

- an `{extern}` FUNCTION is an import, it has no body to export.
- a `{test}` FUNCTION is already exported for `rk test`, and left out of a release build.
- a FUNCTION that takes an interface is compiled once per implementation it is called with.
- a variadic FUNCTION is compiled once per number of arguments it is called with.
- an overloaded FUNCTION shares its name with the other overloads.

Export a plain FUNCTION that calls the one you wanted.

```iecst
{export}
FUNCTION Twice : INT
VAR_INPUT a : INT; END_VAR
    Twice := a * 2;
END_FUNCTION

FUNCTION Twice : REAL
VAR_INPUT a : REAL; END_VAR
    Twice := a * 2.0;
END_FUNCTION
```
