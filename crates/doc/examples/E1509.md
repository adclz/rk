---
title: This FUNCTION cannot be exported
---
An `{export}` FUNCTION is exported under its one name, so it cannot be `{extern}`, `{test}`, variadic, overloaded, or take an interface.
It cannot take a name the module exports itself either (`__init`, `memory`, and the base and size of each memory band), nor can a `{test}`, which is exported in a debug build.

Export a plain FUNCTION that calls it.

```iecst
{export}
FUNCTION Twice : INT
VAR_INPUT a : INT; END_VAR
    Twice := a * 2;
END_FUNCTION

FUNCTION Twice : REAL
VAR_INPUT a : REAL; END_VAR
    Twice := a * 2.0;
END_FUNCTION
```
