---
title: FUNCTION not exportable
---
An `{export}` FUNCTION is exported under its one name: it cannot be `{extern}`, `{test}`, variadic, overloaded, or take an interface or an `ARRAY[*]`.

A host calls it through a function typed in WIT, which takes values and returns one. So it takes scalars and STRINGs as VAR_INPUT, 16 values at most with a STRING counting two, and returns a scalar, a STRING or nothing. Its VAR_OUTPUT are scalars and STRINGs too, returned with the return value as one record. It cannot have a VAR_IN_OUT, or a `REF_TO`, STRUCT, ARRAY or instance input, output or return value.

It cannot take a name the module exports itself: `__init`, `memory`, the base and the size of each memory band. Neither can a `{test}`, exported in a debug build.

Export a plain FUNCTION that calls it.

```iecst
{export}
FUNCTION Twice : INT
VAR_INPUT a : INT; END_VAR
    Twice := a * 2;
END_FUNCTION

FUNCTION Twice : REAL
VAR_INPUT a : REAL; END_VAR
    Twice := a * 2.0;
END_FUNCTION
```
