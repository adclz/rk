---
title: Constant condition
lint_rule: constant-condition
---
A condition in an IF, WHILE, or REPEAT statement is always TRUE or always FALSE.

A comparison is reported too, wherever it is written, when the type of the value decides it: `u < 0` on an unsigned integer is always FALSE, `s <= 127` on a SINT always TRUE, `l > 10` on an `INT (0..10)` always FALSE.
A comparison of two constants is not, `DEBUG > 2`, since a CONSTANT is there to switch code on and off.

```iecst
FUNCTION test : INT
    IF TRUE THEN
        test := 1;
    END_IF;
END_FUNCTION
```
