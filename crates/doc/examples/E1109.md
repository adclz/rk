---
title: SUPER() called in a method
---
`SUPER()` (the base function-block body call) may only appear in the function block body, not in a method of a function block.

```iecst
FUNCTION_BLOCK base
END_FUNCTION_BLOCK

FUNCTION_BLOCK derived EXTENDS base
    METHOD m1
        SUPER()
    END_METHOD
END_FUNCTION_BLOCK
```
