---
title: Global accessed without VAR_EXTERNAL
lint_rule: global-without-external
---
A configuration VAR_GLOBAL is read directly by name. Strict IEC wants the program to import it explicitly with VAR_EXTERNAL.

```iecst
PROGRAM P
VAR n : INT; END_VAR
    n := gCount;
END_PROGRAM

CONFIGURATION Cfg
    VAR_GLOBAL gCount : INT; END_VAR
    RESOURCE Res ON CPU
        TASK T(INTERVAL := T#10ms, PRIORITY := 1);
        PROGRAM P1 WITH T : P;
    END_RESOURCE
END_CONFIGURATION
```
