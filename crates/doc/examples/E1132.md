---
title: SUPER() with a CLASS base
---
`SUPER()` runs the base function block's body. A FUNCTION_BLOCK may extend a CLASS, which has no body: its methods are reached with `SUPER.Method()`.

```iecst
CLASS Counter
    VAR n : INT; END_VAR
END_CLASS

FUNCTION_BLOCK Ticker EXTENDS Counter
    SUPER();
END_FUNCTION_BLOCK
```
