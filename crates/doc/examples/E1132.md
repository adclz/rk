---
title: SUPER() with a CLASS base
---
`SUPER()` runs the body of the base FUNCTION_BLOCK. A FUNCTION_BLOCK may extend a CLASS, but a CLASS has no body. Its methods are reached with `SUPER.Method()`.

```iecst
CLASS Counter
    VAR n : INT; END_VAR
END_CLASS

FUNCTION_BLOCK Ticker EXTENDS Counter
    SUPER();
END_FUNCTION_BLOCK
```
