---
title: {must_call} instance never called
lint_rule: must-call-violation
---
An instance of a FUNCTION_BLOCK marked `{must_call}` is declared and never called.
A timer that is never called never expires, and an edge detector never sees an edge.

An instance counts as called when its body is called, `t(...)`, in the POU that declares it or in one of that POU's methods, or when it is handed on by reference, to a VAR_IN_OUT, an output or `REF()`, or named in the configuration.
A method call, `t.m()`, does not run the body.

```iecst
{must_call}
FUNCTION_BLOCK Delay
VAR_INPUT
    start : BOOL;
END_VAR
VAR_OUTPUT
    done : BOOL;
END_VAR
    done := start;
END_FUNCTION_BLOCK

PROGRAM Main
VAR
    d : Delay;
    lamp : BOOL;
END_VAR
    lamp := d.done;
END_PROGRAM
```
