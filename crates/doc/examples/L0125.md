---
title: Same storage passed twice by reference
lint_rule: in-out-alias
---
One call passes the same storage to two VAR_IN_OUT parameters, or to a VAR_IN_OUT and an output.
Both parameters reach the same variable, so a write through one changes what the other reads, and the result depends on the order of the callee's writes.

A STRUCT and one of its fields overlap, and so does an element passed twice at the same constant or variable subscript.
Two elements at subscripts that may differ, `v[i]` and `v[j]`, are not reported: that is how a sort swaps them.

A global passed to a VAR_IN_OUT is the same storage under two names when the callee also reaches it by VAR_EXTERNAL, in its own body or in what it calls.

```iecst
FUNCTION Swap
VAR_IN_OUT
    a : INT;
    b : INT;
END_VAR
VAR
    t : INT;
END_VAR
    t := a;
    a := b;
    b := t;
END_FUNCTION

FUNCTION Demo : INT
VAR
    x : INT := 1;
END_VAR
    Swap(a := x, b := x);
    Demo := x;
END_FUNCTION
```
