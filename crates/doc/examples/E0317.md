---
title: Type name used as a value
---
A type name is not a value, and neither is the name of a FUNCTION or METHOD outside its own body. Call the FUNCTION instead.

```iecst
TYPE b1 : INT
END_TYPE

FUNCTION fn1
    VAR_OUTPUT
        param1: INT;
    END_VAR
END_FUNCTION

FUNCTION_BLOCK fb1
    fn1(param1 => b1);
END_FUNCTION_BLOCK
```
