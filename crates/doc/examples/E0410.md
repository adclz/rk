---
title: More values than fields
---
A STRUCT's initializer may give its values without names, `(1, 2)`. Each one sets the next field that no value names, in the order the fields are declared.

A value after the last such field has no field to go to.

```iecst
TYPE
    Point : STRUCT
        x : INT;
        y : INT;
    END_STRUCT;
END_TYPE

PROGRAM P
VAR
    p : Point := (1, 2, 3);
END_VAR
    p.x := p.y;
END_PROGRAM
```
