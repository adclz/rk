---
title: VAR_OUTPUT argument not a variable
---
A call writes an output into the variable bound to it, with `=>` or in its place in a positional list. The argument is a variable, not an expression or a literal.

```iecst
FUNCTION Give
VAR_OUTPUT o : INT; END_VAR
    o := 1;
END_FUNCTION

FUNCTION f1
VAR x : INT; END_VAR
    Give(o => x + 1);
END_FUNCTION
```
