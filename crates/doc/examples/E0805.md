---
title: Output parameter used as input
---
A positional argument lands on a VAR_OUTPUT. An output is bound by name, with `=>`.

```iecst
FUNCTION fn1
    VAR_INPUT
        a: INT;
    END_VAR
    VAR_OUTPUT
        b: INT;
    END_VAR
END_FUNCTION

FUNCTION_BLOCK fb1
    fn1(1, 2);
END_FUNCTION_BLOCK
```
