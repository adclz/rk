---
title: Cannot access INTERNAL item
---
INTERNAL items can only be accessed from within the same namespace.

```iecst
NAMESPACE ns1
    CLASS Base
        METHOD INTERNAL myInternalMethod : INT  END_METHOD
    END_CLASS
END_NAMESPACE

NAMESPACE ns2
    USING ns1;

    CLASS Mid EXTENDS Base
        METHOD testMethod : INT
            SUPER.myInternalMethod();
        END_METHOD
    END_CLASS
END_NAMESPACE
```
