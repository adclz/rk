---
title: Method return type mismatch
---
A method implementing an interface prototype or overriding a base method declares a different return type, or a return type where the base has none. A caller through the base signature reads the base's type.

```iecst
INTERFACE I
    METHOD M : INT
    END_METHOD
END_INTERFACE

CLASS C IMPLEMENTS I
    METHOD M : REAL
        M := 0.0;
    END_METHOD
END_CLASS
```
