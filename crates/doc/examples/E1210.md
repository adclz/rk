---
title: jump out of a __FINALLY
---
`RETURN`, `EXIT` and `CONTINUE` cannot be used to leave a `__FINALLY`.

A `__FINALLY` also runs when an exception was not caught.
Leaving it with a jump would cancel that exception without any `__CATCH`.

Write the jump after `__END_TRY` instead.

`__RAISE` is accepted in a `__FINALLY`, it replaces the exception in progress.

```iecst
FUNCTION f1 : INT
    __TRY
        f1 := 1;
    __FINALLY
        RETURN;
    __END_TRY;
END_FUNCTION
```
