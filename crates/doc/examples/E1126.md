---
title: Method parameter type mismatch
---
A parameter has another type than the one at the same position in the method it implements or overrides.

No widening applies, and `INT...` is not `INT`: a variadic parameter is variadic on both sides.

```iecst
INTERFACE I
    METHOD M : INT
        VAR_INPUT a : INT; END_VAR
    END_METHOD
END_INTERFACE

CLASS C IMPLEMENTS I
    METHOD M : INT
        VAR_INPUT a : REAL; END_VAR
        M := 0;
    END_METHOD
END_CLASS
```
