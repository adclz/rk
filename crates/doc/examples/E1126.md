---
title: Method parameter type mismatch
---
A parameter of a method implementing an interface prototype or overriding a base method has a different type than the parameter at the same position in the base.

Widening does not apply: a call through the base signature passes the base's type.

```iecst
INTERFACE I
    METHOD M : INT
        VAR_INPUT a : INT; END_VAR
    END_METHOD
END_INTERFACE

CLASS C IMPLEMENTS I
    METHOD M : INT
        VAR_INPUT a : REAL; END_VAR
        M := 0;
    END_METHOD
END_CLASS
```
