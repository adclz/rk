---
title: TASK or PROGRAM outside a RESOURCE
---
A CONFIGURATION contains RESOURCE blocks; the tasks and the programs bound to them are declared inside one. Wrap them in `RESOURCE <name> ON <cpu> ... END_RESOURCE`.

```iecst
PROGRAM prog1
END_PROGRAM

CONFIGURATION cfg1
    TASK t1(INTERVAL := T#10ms, PRIORITY := 1);
    PROGRAM inst1 WITH t1 : prog1;
END_CONFIGURATION
```
