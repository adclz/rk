---
title: Interface type outside a parameter
---
An interface type is a `VAR_INPUT` or `VAR_IN_OUT` parameter of a FUNCTION or METHOD, passed by reference: the caller's type replaces it and its methods run on the caller's instance.

It cannot be a variable, a member, an output, a global, or an input of a FUNCTION_BLOCK: an instance would store it across calls.

```iecst
INTERFACE ITF1
    METHOD DoWork END_METHOD
END_INTERFACE

PROGRAM Main
    VAR
        dev : ITF1;
    END_VAR
END_PROGRAM
```
