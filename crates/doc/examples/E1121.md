---
title: Interface type only allowed as a parameter
---
An interface type can only be a `VAR_INPUT` or `VAR_IN_OUT` parameter, where the caller's type replaces it.

It cannot be a variable, a member, an output or a global.

```iecst
INTERFACE ITF1
    METHOD DoWork END_METHOD
END_INTERFACE

PROGRAM Main
    VAR
        dev : ITF1;
    END_VAR
END_PROGRAM
```
