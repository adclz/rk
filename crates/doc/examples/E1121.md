---
title: Interface type only allowed as a parameter
---
An interface type may appear only as a `VAR_INPUT` or `VAR_IN_OUT` parameter, where it is monomorphized to the concrete type passed by the caller. It cannot be a stored `VAR`, member, `VAR_OUTPUT`, `VAR_TEMP`, or global.

```iecst
INTERFACE ITF1
    METHOD DoWork END_METHOD
END_INTERFACE

PROGRAM Main
    VAR
        dev : ITF1;
    END_VAR
END_PROGRAM
```
