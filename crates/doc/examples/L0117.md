---
title: External instance mutation
lint_rule: external-mutation
---
A field of a FUNCTION_BLOCK or CLASS instance is written from outside the instance, which should own its data.

A part of a field is the field written: `fb.x[0] := 1` and `fb.s.a := 1` are reported too.

An input is not reported: `fb.x := 42` before `fb()` passes it, as `fb(x := 42)` does.

```iecst
FUNCTION_BLOCK MyFB
VAR
    x : INT;
END_VAR
END_FUNCTION_BLOCK

FUNCTION caller : INT
VAR
    fb : MyFB;
END_VAR
    fb.x := 42;
END_FUNCTION
```
