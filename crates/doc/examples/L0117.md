---
title: External instance mutation
lint_rule: external-mutation
---
A field of a function block or class instance is directly modified from outside.
Instances should own their data.

```iecst
FUNCTION_BLOCK MyFB
VAR
    x : INT;
END_VAR
END_FUNCTION_BLOCK

FUNCTION caller : INT
VAR
    fb : MyFB;
END_VAR
    fb.x := 42;
END_FUNCTION
```
