---
title: STRING into a shorter STRING
lint_rule: string-truncation
---
A STRING variable is assigned, passed or bound to a STRING declared shorter.
The text is cut to the capacity of the target, so what is past it is lost without a trace.

A plain STRING holds 80 bytes.
A literal is measured by E0314 instead, and a call's result is not reported: it is as long as its type, STRING[255] for CONCAT.

```iecst
FUNCTION Label : STRING[8]
VAR_INPUT
    name : STRING[32];
END_VAR
    Label := name;
END_FUNCTION
```
