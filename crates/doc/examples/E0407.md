---
title: Aggregate default on a FUNCTION or METHOD input
---
An input of a FUNCTION or METHOD keeps nothing between calls. Its default is what the caller passes when the argument is omitted, and that is a constant of an elementary type, STRING included (E0802).

A STRUCT or ARRAY initializer on such an input can never apply: a call either passes the argument or is refused. The initializer is refused where it is written.

Set the value in the body, or pass it in every call.

```iecst
TYPE Pt : STRUCT x : INT; y : INT; END_STRUCT; END_TYPE

FUNCTION sum : INT
VAR_INPUT p : Pt := (x := 4, y := 5); END_VAR
    sum := p.x + p.y;
END_FUNCTION
```
