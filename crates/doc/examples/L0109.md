---
title: Duplicate CASE value
lint_rule: duplicate-case
---
Two or more CASE branches use the same selector value. Only the first branch will ever match.

```iecst
FUNCTION test : INT
VAR
    x : INT;
END_VAR
    CASE x OF
        1: test := 10;
        1: test := 20;
    END_CASE;
END_FUNCTION
```
