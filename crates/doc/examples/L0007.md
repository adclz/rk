---
title: {must_call} instance called only in a branch
lint_rule: must-call-conditional
---
An instance of a FUNCTION_BLOCK marked `{must_call}` is called only inside an IF, a CASE or a loop, so a scan that skips the branch skips the call.
A block sees its inputs only when it is called: a timer called in an IF never sees its input go FALSE, and keeps the state it had when the branch stopped running.
A timer shared between two steps of a CASE starts the second step with the time the first left on it.

Call the instance once at every scan, outside the branch, and pass the condition as an input: `d(start := auto_mode)`.

An instance called in a method, handed on by reference, called from outside its block or named by the configuration runs at times the body does not show, and is not reported.
Nor is an array of instances: a FOR over it calls each element.

```iecst
{must_call}
FUNCTION_BLOCK Delay
VAR_INPUT
    start : BOOL;
END_VAR
VAR_OUTPUT
    done : BOOL;
END_VAR
    done := start;
END_FUNCTION_BLOCK

PROGRAM Main
VAR
    d : Delay;
    auto_mode : BOOL;
    lamp : BOOL;
END_VAR
    IF auto_mode THEN
        d(start := TRUE);
    END_IF;
    lamp := d.done;
END_PROGRAM
```
