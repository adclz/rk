---
title: Subrange mismatch across a reference
---
A VAR_IN_OUT argument or an output destination binds the callee to the caller's storage by reference, so both ends must agree about the subrange.

A callee writing through a plain INT would otherwise go around the range check of the caller's INT (0..10).

```iecst
TYPE Small : INT (0..10); END_TYPE

FUNCTION scribble
VAR_IN_OUT
    x : INT;
END_VAR
    x := 0;
END_FUNCTION

FUNCTION f1 : INT
VAR
    s : Small;
END_VAR
    scribble(x := s);
END_FUNCTION
```
