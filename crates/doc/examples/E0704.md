---
title: Subrange mismatch across a reference
---
A VAR_IN_OUT argument or an output binds the caller's own variable, so both sides have the same subrange.

Otherwise the callee could bypass the caller's range check.

```iecst
TYPE Small : INT (0..10); END_TYPE

FUNCTION scribble
VAR_IN_OUT
    x : INT;
END_VAR
    x := 0;
END_FUNCTION

FUNCTION f1 : INT
VAR
    s : Small;
END_VAR
    scribble(x := s);
END_FUNCTION
```
