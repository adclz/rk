---
title: VAR_EXTERNAL not allowed in this context
---
`VAR_EXTERNAL` imports a global into a FUNCTION, FUNCTION_BLOCK, PROGRAM, CLASS or METHOD. A METHOD prototype in an INTERFACE has no body to read it, and a CONFIGURATION declares the globals themselves.

```iecst
INTERFACE in
    METHOD m
        VAR_EXTERNAL

        END_VAR
    END_METHOD
END_INTERFACE
```
