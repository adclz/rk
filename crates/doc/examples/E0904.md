---
title: Reference in RETAIN storage
---
A RETAIN variable holds a reference, itself or in a field or member, or a struct field marked `RETAIN` does. A warm start restores the address, but a new build may have moved its target.

Keep the reference out of RETAIN, `NON_RETAIN` on a member or a field, and set it in the first scan.

```iecst
TYPE PInt : REF_TO INT; END_TYPE

PROGRAM Main
VAR
    x : INT;
END_VAR
VAR RETAIN
    p : PInt;
END_VAR
    p := REF(x);
END_PROGRAM
```
