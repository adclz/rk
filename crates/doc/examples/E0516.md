---
title: Member value outside an element's parentheses
---
An element of an array of structures or instances is one value, its members in parentheses: `[(x := 5, y := 6)]`.

A member's value written straight in the brackets belongs to no element.

```iecst
TYPE Point : STRUCT x : INT; y : INT; END_STRUCT; END_TYPE

PROGRAM P
VAR
    points : ARRAY[0..1] OF Point := [x := 5, y := 6];
END_VAR
    points[0].x := points[1].y;
END_PROGRAM
```
