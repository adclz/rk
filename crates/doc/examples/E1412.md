---
title: Program instance without a task
---
Every program instance in a RESOURCE is attached to a TASK with `WITH`, and an unattached instance is never scheduled.

```iecst
PROGRAM P
VAR n : INT; END_VAR
    n := n + 1;
END_PROGRAM

CONFIGURATION Cfg
    RESOURCE Res ON CPU
        PROGRAM P1 : P;
    END_RESOURCE
END_CONFIGURATION
```
