---
title: Program instance without a task
---
Every program instance in a RESOURCE must be attached to a TASK with `WITH` - an unattached instance would never be scheduled.

```iecst
PROGRAM P
VAR n : INT; END_VAR
    n := n + 1;
END_PROGRAM

CONFIGURATION Cfg
    RESOURCE Res ON CPU
        PROGRAM P1 : P;
    END_RESOURCE
END_CONFIGURATION
```
