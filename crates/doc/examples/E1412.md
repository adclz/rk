---
title: Program instance without a task
---
Every program instance in a RESOURCE names a TASK with `WITH`: rk runs a program only under a task, where the standard would run one without at the lowest priority.

```iecst
PROGRAM P
VAR n : INT; END_VAR
    n := n + 1;
END_PROGRAM

CONFIGURATION Cfg
    RESOURCE Res ON CPU
        PROGRAM P1 : P;
    END_RESOURCE
END_CONFIGURATION
```
