---
title: Unused variable
lint_rule: unused-variable
---
A variable is declared but never used in the body.

A global of the configuration is reported when no POU of the workspace uses it, through a `VAR_EXTERNAL` or by its own name.
A name that starts with an underscore marks a variable kept on purpose, and is not reported.

```iecst
FUNCTION fn1 : INT
VAR
    x : INT;
    y : INT;
END_VAR
    fn1 := x;
END_FUNCTION
```
