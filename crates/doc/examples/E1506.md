---
title: Wasm operand not declared
---
A {wasm} statement runs its instruction on the operands it names and writes the one its (result) names, so each must be a parameter, a local or the return of the FUNCTION.

An unknown name used to be ignored: the FUNCTION's own parameter list was lowered instead and the pragma's operands were decoration.

```iecst
FUNCTION Root : REAL
VAR_INPUT
    a : REAL;
END_VAR
    {wasm 'f32.sqrt' (params b) (result Root)}
END_FUNCTION
```
