---
title: Export pragma outside a FUNCTION
---
An {export} pragma is valid only on a FUNCTION: it is the one POU a host can call with nothing but its parameters.

A PROGRAM is already exported, the schedule names it. A FUNCTION_BLOCK or a METHOD needs an instance, and the host does not have one.

Wrap the call in a FUNCTION and export that.

```iecst
{export}
FUNCTION_BLOCK Motor
VAR_INPUT run : BOOL; END_VAR
END_FUNCTION_BLOCK
```
