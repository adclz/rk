---
title: Export pragma outside a FUNCTION
---
`{export}` is valid only on a FUNCTION.

A PROGRAM is already exported, and a FUNCTION_BLOCK or METHOD needs an instance: wrap the call in a FUNCTION and export that.

```iecst
{export}
FUNCTION_BLOCK Motor
VAR_INPUT run : BOOL; END_VAR
END_FUNCTION_BLOCK
```
