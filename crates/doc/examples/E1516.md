---
title: Stream built-in that does not fit its declaration
---
A stream's or a future's built-in is imported beside a WASI function whose type has the stream, under that function's name: `[stream-new-0]write-via-stream` makes the stream of `write-via-stream`'s type.

A built-in that returns at once, `new` or a drop, is an `{extern}` FUNCTION. A `new` declares the two ends it makes, a UDINT VAR_OUTPUT each, the reading end first, and no return type. A stream's write waits for the stream's reader, so it is an `{extern async}` FUNCTION_BLOCK, whose calls start the copy and check it. A read is not imported.

A stream write takes the stream's writing end, a `UDINT`, then the bytes, a `STRING`, and gives after `DONE` how many went, a `UDINT`, then whether the reader left, a `BOOL`.

```iecst
{extern 'wasi:cli/stdout@0.3.0' '[stream-write-0]write-via-stream'}
FUNCTION WriteNow : UDINT
VAR_INPUT stream : UDINT; END_VAR
END_FUNCTION
```
