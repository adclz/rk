---
title: Unnecessary ELSE
lint_rule: unnecessary-else
---
The ELSE branch is unnecessary because all preceding IF/ELSIF branches end with RETURN, EXIT, or CONTINUE.

```iecst
FUNCTION test : INT
VAR
    x : INT;
END_VAR
    IF x > 0 THEN
        test := 1;
        RETURN;
    ELSE
        test := 0;
    END_IF;
END_FUNCTION
```
