---
title: Duplicate element in an initializer
---
An array initializer writes the same element twice: at its index, `[1] := 9`, after the values before it already filled that cell, or after another index.

```iecst
FUNCTION_BLOCK fb1
VAR
    x : ARRAY[0..3] OF INT := [1, 2, [1] := 9];
END_VAR
END_FUNCTION_BLOCK
```
