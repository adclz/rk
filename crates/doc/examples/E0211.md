---
title: Edge input written or referenced
---
Inside its own block, an edge input is the edge computed when the call starts, not the value the caller passed.

From outside the block, `fb.start` is the value the caller passed. You can write it, reference it or pass it to a VAR_IN_OUT there.

```iecst
FUNCTION_BLOCK Latch
VAR_INPUT
    start : BOOL R_EDGE;
END_VAR
    start := FALSE;
END_FUNCTION_BLOCK
```
