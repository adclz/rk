---
title: {warn} notice
lint_rule: warn-pragma
---
A call targets a POU annotated `{warn = '...'}`: the warning, a deprecation for instance, is shown at the call site.

```iecst
{warn = 'this function is deprecated, use fn2 instead'}
FUNCTION fn1 : INT
END_FUNCTION

FUNCTION caller : INT
VAR x : INT; END_VAR
    x := fn1();
END_FUNCTION
```
