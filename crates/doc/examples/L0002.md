---
title: Warning pragma notice
lint_rule: warn-pragma
---
A call targets a POU annotated with `{warn = '...'}`, indicating deprecation or other warnings at the call site.

```iecst
{warn = 'this function is deprecated, use fn2 instead'}
FUNCTION fn1 : INT
END_FUNCTION

FUNCTION caller : INT
VAR x : INT; END_VAR
    x := fn1();
END_FUNCTION
```
