---
title: Recursive call
lint_rule: recursion
---
A call leads back to the POU making it, directly or through other POUs. IEC 61131-3 has no recursion, and rk allows it.

A recursive POU gets a frame on the stack at each call for its arrays, strings, structures and instances. Any other POU keeps them at a fixed address and never touches the stack.

The stack holds 64 KiB, and nothing bounds the depth before the program runs: too deep a recursion stops it with `stack overflow`. A loop does the same work in a fixed amount of memory.

```iecst
FUNCTION SumTo : DINT
VAR_INPUT n : DINT; END_VAR
    IF n > 0 THEN
        SumTo := n + SumTo(n - 1);
    END_IF;
END_FUNCTION
```
