---
title: Collapsible IF
lint_rule: collapsible-if
---
Two nested IF statements without ELSE branches can be collapsed into a single `IF a AND b THEN`.

```iecst
FUNCTION test : INT
VAR
    a : BOOL;
    b : BOOL;
END_VAR
    IF a THEN
        IF b THEN
            test := 1;
        END_IF;
    END_IF;
END_FUNCTION
```
