---
title: STRING length is negative
---
The `n` of `STRING[n]` is how many bytes the variable holds, so it cannot be below zero.

Constant arithmetic wraps at its type like any other, so `STRING[200 * 200]` is an INT product, -25536. Write `DINT#200 * 200` to compute it in `DINT`.

```iecst
FUNCTION fn1 : INT
VAR
    s : STRING[-5];
END_VAR
    fn1 := 1;
END_FUNCTION
```
