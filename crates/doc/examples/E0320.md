---
title: Negative STRING length
---
The `n` of `STRING[n]` is a byte count: it cannot be negative.

Constant arithmetic wraps at its type: `STRING[200 * 200]` is an INT product, -25536. Write `DINT#200 * 200` to compute it in DINT.

```iecst
FUNCTION fn1 : INT
VAR
    s : STRING[-5];
END_VAR
    fn1 := 1;
END_FUNCTION
```
