---
title: Unexpected variable initialization
---
An initial value is not allowed in this section. A `VAR_TEMP` is made afresh at each call, and a `VAR_IN_OUT` of a `FUNCTION` or a `METHOD`, or of an aggregate type, is bound to the caller's variable at each call, so neither has anything of its own to initialize. A `FUNCTION_BLOCK` keeps a `VAR_IN_OUT` of a scalar type as a member, which takes one.

```iecst
FUNCTION fn1 : INT
VAR_IN_OUT
    x : INT := 5;
END_VAR
    fn1 := x;
END_FUNCTION
```
