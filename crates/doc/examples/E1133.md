---
title: SUPER calls a method with no body
---
`SUPER.Method()` runs the base's own method.

An ABSTRACT one has no body to run, nor does one the base takes from an INTERFACE without implementing it.

```iecst
FUNCTION_BLOCK ABSTRACT Shape
    METHOD PUBLIC ABSTRACT Area : INT
    END_METHOD
END_FUNCTION_BLOCK

FUNCTION_BLOCK Square EXTENDS Shape
    METHOD PUBLIC OVERRIDE Area : INT
        Area := SUPER.Area() + 4;
    END_METHOD
END_FUNCTION_BLOCK
```
